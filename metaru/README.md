# Meta-RU vs GRU vs LSTM 对比实验

## 模型

**Meta-RU**（元可塑性循环单元，源自混沌逻辑斯蒂映射的序列化推演）:

```
r_t = sigmoid(Wr·h + Ur·u + 2R - 1)     # 快门控 (R=慢速内参经 logit 注入)
g_t = r_t * h * (1 - h)                  # 二次繁衍项
a_t = W·h + U·u                          # 耦合与注入 (未门控)
h_t = (1-r_t)·h + r_t·g_t + a_t  [clamp 0,1]
R   <- R + eta*(rho - mean(h))*R         # 慢速内稳态 (无梯度)
```

对照: `nn.GRU` / `nn.LSTM`，同隐藏维度 (任务1/2: d=128, 任务3: d=256)、同优化器
(AdamW 1e-3, clip 1.0)、同训练步数。

## 结果

| 任务 | Meta-RU | GRU | LSTM | 判定 |
|---|---|---|---|---|
| adding T=200 (MSE↓, 基线 0.0067) | 0.0081 | **0.0001** | 0.0080 | GRU 完胜; Meta-RU 与 LSTM 均未突破"预测均值"基线 |
| copy T=100 (acc↑, 随机 12.5%) | 6.3% | 6.4% | 6.3% | 三者均未学会 (预算不足, 任务不具区分度) |
| char-LM ctx=128 (loss↓, vocab 2771) | 2.351 | **1.785** | 1.932 | GRU > LSTM > Meta-RU (ppl: 6.0 / 6.9 / 10.5) |

## 分析

1. **Meta-RU 在记忆型任务上失败**: adding 的 MSE 卡在"输出均值"水平。机理:
   - 候选态 `g = r·h·(1-h)` 最大只有 `r/4`，状态单步变化幅度受限，无法快速写入信息;
   - `a_t = W·h + U·u` 未被门控，每步无条件注入，配合 clamp(0,1) 使状态被钉在边界上，
     clamp 处梯度为零 → 内部状态大面积饱和，无法响应标记位。
2. **LM 任务上能学但偏弱** (2.35 vs GRU 1.79): 说明循环结构本身可传梯度，
   但容量/门控效率低于标准 GRU。
3. **LSTM 在 adding 上也失败** (0.0080): 4k 步 × d=128 的预算对 LSTM 偏小，
   GRU 的门结构在此预算下收敛优势明显。
4. **copy 任务三者全败**: 4000 步不足以让 d=128 的 RNN 学会 T=100 的精确间接寻址，
   该任务在本预算下不具区分度 (需加长训练或加 curriculum)。

## 调优扫描 (metaru_tune.py, adding T=200, 28 配置)

### Meta-RU 变体
| 变体 | 最优 eval | 结论 |
|---|---|---|
| v0 原版 | 0.0081 | 失败 (预测均值) |
| v1 eta=0 | 0.0079 | 内稳态关闭略好, 仍失败 |
| **v2 eta=0 + 门控注入** | **0.00009** | **救活!** 90× 提升, 追平 GRU |
| v3/v4 去掉 clamp | **NaN** | clamp 是发散保险丝, 不能去 |
| v5 v2 + r_init=0.5 (非混沌) | 0.00016 | **混沌边缘初始化非必要** |

### 关键发现
1. **调优改变排名**: Meta-RU 0.0081 → 0.00009 (90×)。病根 = 未门控的注入项 `a_t`,
   修复 `h = (1-r)h + r(g + a)` 后即可学习; 内稳态 eta 必须关零。
2. **最终排名**: GRU(2层) 0.00002 > MetaRU(v2) 0.00009 > LSTM(全配置失败) 0.0080
3. **0.008 平台是优化陷阱**: 28 配置中 24 个卡在 0.008——包括全部 1 层 GRU 和全部 LSTM。
   该任务存在尖锐的"会/不会"相变, 只有 lr=1e-3 的 2 层 GRU 和修复版 Meta-RU 跨过。
4. **混沌边缘无增益**: r_init=0.5 (非混沌) 与 0.875 (混沌) 表现相当。

## 结合实验 (hybrid_compare.py, 与 metaru_vs_gru 报告交叉互证, 2 种子均值)

吸收对方报告的 MetaGRU 混合设计 (繁殖项只进重置门) 与混沌判别任务, 加入我方 v2 修正:

| 任务 | GRU | MetaGRU-reset (对方设计) | MetaRU-v2 (我方修正) |
|---|---|---|---|
| adding T=200 (MSE↓) | 0.00467 | **0.00004** | 0.00278 |
| 混沌判别 T=64 (ACC) | 100% | 100% | 100% |
| char-LM (loss↓) | **1.842** | 1.885 | 2.344 |

### 互证结论
1. **对方的分层设计是对的且更稳**: "候选态管内容、门管策略" 的 MetaGRU 在 adding 上
   2 种子稳定 0.00004 (我方 v2 修正 0.00278 且种子敏感, LM 也差 0.04)。
   繁殖项进重置门 > 进候选态 > 原版混写。
2. **混沌判别优势是容量 artifact**: 对方报告 GRU 92.2% vs metagru 95.6% (d=32 CPU),
   我这边 d=128 时三者全 100%——小容量下混沌态表征占优, 容量足够后 GRU 饱和追平。
3. **LM 上 GRU 仍最快**: metagru 1.885 略逊 GRU 1.842 (差距 0.04), 但远好于原版 (2.35+)。
4. 两边独立实现得到一致定性结论: 原版失败、clamp 必需、eta 内稳态无益、
   门控注入方向正确但"进门不进候选"才是正解。

### 若要救活 Meta-RU 的可能方向
- 候选态换 `tanh(W_h·h)` 幅度自由化 (等价于退回 GRU);
- `a_t` 用 `(1-r_t)` 门控注入;
- clamp 换 `sigmoid` 输出门 (有界但梯度不死于边界);
- R 内稳态的 `eta` 调小 1-2 个数量级 (当前 0.05 每步都动, 干扰快门控学习)。

## XGRU: 升级设计 (bench_xgru.py, CUDA Graph 加速, 统一 bs=512 快协议, 2 种子)

XGRU = GRU + (1)候选态内对角循环直达路径 (IndRNN 思想, 绕过重置门的长程梯度) + (2)更新门偏置 +1 初始化

| 任务 | GRU-1L | GRU-2L | LSTM | MetaGRU | XGRU |
|---|---|---|---|---|---|
| add200 (MSE↓) | 0.00754 | 0.00752 | 0.00752 | 0.00009 | 0.00380 |
| add400 (MSE↓) | 0.00787 | 0.00788 | 0.00785 | 0.00048 | 0.00775 |
| 混沌判别 (ACC↑) | 0.9% | 0.9% | 0.9% | 100% | 100% |
| char-LM (loss↓) | 2.291 | 2.328 | 2.583 | 2.322 | 2.259 |

快协议 (bs=512) 下标准 RNN 全线崩溃 (add400 全灭、混沌判别塌到 0.9% 单类塌缩),
两个升级设计跨过优化相变:
- MetaGRU = 记忆专家: add200/400 全场唯一稳定收敛
- XGRU = 全能型: LM 全场第一 (超过 GRU) + 混沌 100% + add200 可跨

### 最终回答 "设计一个超过 GRU 的 GRU"
- 要长程记忆 -> MetaGRU (繁殖项进重置门, T=400 唯一收敛)
- 要全能 (LM+判别) -> XGRU (对角直达 + 门偏置初始化, LM 反超 GRU)
- GRU 默认配置在大 batch 短步数下脆弱 (混沌判别塌到 0.9%), 门偏置初始化与
  对角循环两处一行代码的改动即可大幅改善其优化鲁棒性

- 标准 RNN (GRU/GRU2/LSTM) 在这三项推理测试中全部失败

## 取长补短尝试: MX-GRU (mx_bench.py)

MXGRU = MetaGRU(R 内稳态进重置门) + XGRU(diag 对角直达) + z 偏置+1 叠加

| 指标 | MetaGRU | XGRU | MXGRU |
|---|---|---|---|
| 召回 L=512 | 0.0000 | 0.0000 | 0.0000 |
| 召回 L=1024 | 0.0000 | 0.0192 | 0.0192 |
| 召回 L=2048 | 0.0005 | 0.1401 | 0.1523 |
| 召回 L=4096 | 0.0033 | 0.4903 | 0.4485 |
| LM CE | 2.130 | 2.058 | 2.106 |
| 生成 distinct2 | 0.105 | 0.315 | 0.287 |

结论: 取长补短失败, 两机制互斥. MXGRU 完全复刻 XGRU 的长程衰减曲线
(0.019->0.15->0.45), MetaGRU 的 8x 外推能力未遗传. 机制解读: diag 旁路
独立于门控给 h 提供直达通道, 稀释了 R 内稳态对重置门的控制力; diag 主导
长程行为后 R 记忆机制失效. 若让 diag 也受 R 门控调制或可调和, 留作后续.

## 调和尝试 #2: R 门控 diag (mx_bench2.py, mx-rup/mx-rdn)

diag 注入乘 R 门控: rup (R 高时直通开) / rdn (R 低时直通开), 让 R 统一控制两机制

| 召回外推 | L=512 | L=1024 | L=2048 | L=4096 |
|---|---|---|---|---|
| MetaGRU | 0.0000 | 0.0000 | 0.0005 | 0.0033 |
| XGRU | 0.0000 | 0.0192 | 0.1401 | 0.4903 |
| mx-rup | 0.0000 | 0.0424 | 0.2696 | 0.6160 |
| mx-rdn | 0.0000 | 0.0317 | 0.2013 | 0.5686 |

LM: XGRU CE=2.058 best; mx-rup 2.365 / mx-rdn 2.368 (变差)
结论: R 门控 diag 两方向均失败 (比 always 模式更差). MetaGRU 的长程记忆对
任何 diag 直达旁路结构性过敏——diag 给 h 一条不受 z 门控的遗忘旁路, R 内稳态
无法补偿. 三次尝试 (always/rup/rdn) 均证实两机制互斥, 取长补短不可行.
