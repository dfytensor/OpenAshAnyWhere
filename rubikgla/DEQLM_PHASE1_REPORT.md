# DEQ-LM Phase 1 实验报告 (v1→v3)

日期: 2026-09-28 | 模型: 7.27M (d128, 2+DEQ+2 三明治, vocab 23005) | 数据: minimind PT 1.21M seqs, 3000 步

## 架构

```
emb+pos → LN → 2×标准层 → [权重绑定块 ×k] → 2×标准层 → LN → head
绑定块: z ← z + α·Block(z), Block = causal attn + SwiGLU, α 可学习 (sigmoid 参数化, init 0.1)
```

## 关键结果 (val NLL, 256 token 全序列)

### 1. 深度单调缩放 ✓ (v3, 无谱范数约束)

| k (绑定块迭代次数) | 1 | 2 | 4 | 8 | 16 | 30 |
|---|---|---|---|---|---|---|
| NLL | 6.2712 | 5.9971 | 5.4962 | 4.8575 | 4.4345 | **4.3599** |

- k=30 **胜过** 无 DEQ 的 4 层普通对照 (4.3945) — 绑定块贡献真实容量
- α 训练中自发收缩 0.100 → 0.091 (温和更新)

### 2. 不动点收敛 ✗ (诚实负结果)

- 相对残差稳定在 ~0.15/步, 30 步后远大于 tol=1e-3 → **从不收敛**
- 该块的实际语义是"权重绑定深度"(Universal Transformer/ALBERT 类), 不是 DEQ 不动点解算器
- 谱范数约束 + α=0.1 + DEQ lr×0.1 (v2) 也无法强制收缩, 且限制容量: v2 k=30 NLL 4.4505 差于对照 4.3945

### 3. 残差探针: 弱正向信号

- 残差-NLL 相关 = **+0.268** (100 样本, 非 pad 位置, 残差范围 0.123~0.168)
- 方向与理论一致 (难样本残差大), 但强度远弱于合成任务上的 3.2× 分离

### 4. maxprob 置信度早退 ✗ (重要负结果)

| τ | avg_k | NLL |
|---|---|---|
| 0.00 | 1.0 | 6.2734 |
| 0.40 | 12.1 | 5.9805 |
| 0.95 | 26.7 | 6.2135 |
| (全批 k=16 对照) | 16.0 | **4.4345** |
| (全批 k=30 对照) | 30.0 | **4.3599** |

- **逐位置早退全面劣于统一深度**: avg_k=26.7 的 NLL (6.21) 竟远差于全批只用 16 步 (4.43)
- 原因: 中间深度的 logits **"自信但错误"** — maxprob 在 k~8 就饱和, 但预测质量到 k~30 才到位
- 评测边界自洽验证: τ=0 (全部 k=1) 给 6.2734 ≈ 精确 k=1 的 6.2712 ✓

## 与 MiniCPM5 教训的呼应

MiniCPM5: "表示收敛 ≠ 输出收敛" → DEQ-LM v3: "**输出置信 ≠ 输出质量**"
置信度类 halting 信号 (maxprob) 与预测质量解耦是跨架构的普遍现象。
有效的早退需要**训练时**的 ponder/halting 监督 (ACT), 事后 maxprob 不可用。

## 调试过程中抓到的三个架构级 bug (值得记录)

1. **h_deq 丢弃 bug** (v2): `h_deq` 算完未接入 top 层, DEQ 块完全旁路 — 前两轮"k 扫描无差异"的真正原因
2. **α 参数化 bug** (v2): `sigmoid(0.1)=0.525` 而非 0.1; 正确做法是 `sigmoid(logit(α))` 或直接参数化 α
3. **exact_k 无效 bug** (v2 首版): `n_iter = km if exact_k is not None else km` 恒为 km

## Phase 1 验收对照设计文档

| 设计承诺 | 结果 |
|---|---|
| DEQ 块收敛, 残差→0 | ✗ 不收敛 (0.15/步) — 实为绑定深度语义 |
| 深度单调改善质量 | ✓ k=1→30: 6.27→4.36 |
| 优于同参数普通层 | ✓ 4.3599 < 4.3945 (边际小, 计算多 15×) |
| 残差范数 = 不确定性 | △ +0.268 弱正向 |
| 免训练自适应计算 (maxprob 早退) | ✗ 彻底失败 |
| O(1) 反向显存 (Phantom Gradient) | 未实现 (本轮用普通反传) |

## 结论

- 权重绑定深度块在 LM 上有效但边际收益小、计算代价大 (k=30 才小幅胜出)
- "收敛探针→不确定性"理论路线在此架构上只有微弱支撑 (+0.268)
- 置信度早退失败是比收敛失败更有价值的发现: 它证明 **halting 必须被训练**, 不是免费的
