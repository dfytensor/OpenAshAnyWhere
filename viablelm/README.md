# 可行域语言模型（ViableLM）
## 原理 · 实验 · 代码 · 后续验证路线

> **一句话总纲**
> 不最大化任何标量。定义一组**少数、直接测量、双侧有界**的本质变量，用**带增益预算的双侧回中**把它们维持在可行域内，然后**从受控分布中采样**，而不是取 argmax。
> 自回归不删除，但降格——它从"目标"变成"可行集的生成器"。

# 第一部分 · 原理

## 1.1 十轮推演的结论链

这份报告不是从某个既有理论出发的，而是从一连串追问里**筛**出来的。每一轮都有东西被杀掉，剩下的结构因此越来越简单。

| # | 主张 | 判决 | 依据 |
|---|---|---|---|
| 1 | 文本缺冗余，需要人工造判决域 | ✅ **活** | 紧凑 ≠ 鲁棒；信源编码与信道编码目标相反 |
| 2 | 用连续空间 + 范围约束 + 迭代收敛造冗余 | ✅ **活（有几何约束）** | 维度决定噪声容限：3 维里 5 万 token 的判决域半径仅 0.027；768 维里 0.986 |
| 3 | 用图像当载体（"绝对的视觉"） | ✅ **活** | DeepSeek-OCR：10× 压缩保 97%，20× 保 ~60% |
| 4 | 人类用图像思考 | ❌ **修正** | 思维是**采样过程**，图像是它的一次采样；心盲症（1–4%）照样思考 |
| 5 | 脑是身体↔世界的翻译模型 | ⚠️ **削弱** | 内感受仅 10–40 维 vs 外感受 10⁶，不对称 10⁴:1；Ashby 好调节器定理只要求**同态像**，不是完整仿真 |
| 5' | 脑在做变分贝叶斯 | ❌ **死** | Bowers & Davis：不可证伪的 just-so story；一个能拟合一切的理论保证不了任何东西 |
| 6 | 该做价值模型，别做翻译模型 | ❌ **死** | 标量最大化正是 Goodhart 的燃料——问题不在价值好坏，在"求极值"这个动作 |
| 7 | 用概率框架（后验/KL/采样）防作弊 | ❌ **死** | 概率语言是 as-if 描述，提供不了机制保证 |
| 8 | 做控制器，不做最大化器 | ✅ **核心** | 最大化器无平衡点、无增益、无余量；控制器三者都有 |
| 9 | 可行域 + 双侧回中 + 可解析余量 + 采样 | ✅ **架构** | 本报告 |
| 10 | 多单元耦合 = 外部性生态 | ✅ **扩展** | 相变可解析、预警窗口 6 个数量级 |

**被杀掉的四样东西**：文本的紧凑编码、贝叶斯大脑、标量价值模型、概率防作弊框架。每杀一次，剩下的结构就更简单一点。

## 1.2 核心命题：Goodhart 的灾难形式需要两个前提

先证伪一个常见说法。**如果**代理误差在**全空间**一致有界（‖R̂−R‖∞ ≤ ε），那么 argmax 的后悔 ≤ 2ε——**argmax 本身是安全的**。

真正的机制不是点误差，是**分布偏移**：

> 代理只在**被验证过的分布**上准。优化把你推向分布外，那里误差无界。

而灾难要成立，需要两个前提同时满足：

1. **存在一个无上界的标量**（"越高越好"这个句式）
2. **对它做 argmax / 梯度上升**

**去掉任一个，Goodhart 就断链。** 本架构选择去掉第一个：不用标量，用可行域。

### 为什么"可行域"能断链

| | 最大化器 | 控制器 |
|---|---|---|
| 数学对象 | 无上界标量 → 极值 | 一组双侧有界的量 → **带** |
| 平衡点 | **无** | 有（回中力与诱惑力的平衡） |
| 可调参数 | 无 | **增益 k** |
| 安全余量 | **不存在** | `margin = 半宽 − 诱惑/增益`，解析可预测 |
| 崩溃速度 | 快（WAGGLE：38 轮） | 慢（设定点漂移） |
| 崩溃可见性 | **无声**——代理分还在涨 | **可见**——余量/振荡在独立通道上收缩 |
| 失效形态 | 灾难性反转 | 分级、可预警 |

**关键洞察**：身体不是第二个描述对象，是那个在给描述**打分**的东西。而打分的方式不是"越高越好"，是"在带内"。你不想血糖最大，你想血糖在范围内。

## 1.3 三个反直觉的设计决策

### 决策一：增益不是越大越好——存在内部最优

这是模拟推翻直觉的地方。

**无任务扰动时**（诱惑 vs 回中）：k 越大余量越大，公式 `余量 = 半宽 − 诱惑/增益` 成立。

**有任务扰动时**：

| k | 0.3 | 1.0 | 3.0 | 10.0 |
|---|---|---|---|---|
| 稳态 ‖u‖ | 2.53 | 5.23 | 5.90 | 6.07 |
| 代理腐败 δ | 1.159 | 1.237 | 1.246 | 1.248 |
| **余量** | **0.629** | 0.325 | 0.128 | 0.056 |

```
margin(k) = 半宽 − |残余扰动| − |代理腐败(‖u‖(k))|
                    ↘ k↑              ↗ k↑
```

两项反向，存在内点最优。**恒温器增益越大越好，因为它的传感器不撒谎。LM 的会撒谎，而且你越是努力控制，它撒谎越厉害。**

> **调参铁律**：离线扫描 k，在验证集上取余量峰值。**绝不让 k 对着在线奖励自适应**——否则调增益这件事本身又变成一个被优化的目标。

### 决策二：输出必须采样，不能 argmax

| 代理噪声 σ | argmax 真实分 | 采样 K=32 | argmax 方差 | 采样方差 |
|---|---|---|---|---|
| 0.0 | 2.348 | 0.964 | 0.200 | 0.092 |
| 0.8 | 1.786 | 0.919 | 0.480 | 0.114 |
| 1.6 | 1.265 | 0.842 | **0.669** | **0.166** |

argmax 是**不连续**泛函——噪声一大，它专挑误差最大的那个。采样是连续泛函，对扰动平滑。**代理必然有误差，所以必须采样。**

### 决策三：复杂声明自动变保守——不用写"要谦逊"的规则

思维是采样，则合取事件的有效样本数更少（n′ < n），先验收缩更强：

| 有效样本 n | 40 | 10 | 2 |
|---|---|---|---|
| 简单声明 p̂(A) | 0.700 | 0.657 | 0.573 |
| 合取声明 p̂(A∧B) | 0.442 | 0.459 | 0.486 |

样本越少，估计越向先验 0.5 回归。**保守性是采样机制的必然产物**（与人类的合取谬误同源）。这比在 prompt 里写"不确定时请说明"可靠得多——后者可以被优化掉，前者是机制。

## 1.4 本质变量的三条铁律

| 铁律 | 理由 |
|---|---|
| **必须直接测量，不能是学习出来的** | 一旦可学习，就可被优化穿透。控制器复现：代理侧 ‖ẑ‖max 恒 0.101 从不报警，真实 ‖z‖max 已爬到 0.898 |
| **必须双侧有界** | 只有"越高越好"就重新引入 Goodhart。困惑度：太低=复读，太高=胡言 |
| **维度必须小（8~16）** | 内感受只有 10~40 维。d 一大就无法保证余量。把"质量"压成标量 = d=1 再求极值 |

建议集合（语言模型场景）：

| 变量 | 下界违规 | 上界违规 | 怎么测 |
|---|---|---|---|
| 困惑度 | 复读退化 | 胡言 | 参考模型直接算 |
| token 熵 | 坍缩 | 噪声 | 直接算 |
| 自重复率 | 离题 | 复读 | 直接算 |
| 检索接地率 | 幻觉 | 抄原文 | 与证据重叠 |
| 长度比 | 敷衍 | 灌水 | 直接算 |
| 与提问相关性 | 离题 | 复述问题 | 嵌入相似度 |
| 校准误差 | 过度保守 | 过度自信 | 表达不确定 vs 实际错误 |
| 形式/执行验证 | 语法错、跑不通 | — | 执行器、单元测试 |
| **分布偏移** | — | 离开验证区 | **元变量**，密度估计 |

## 1.5 与现有范式的关系

| | 现状 | 本设计 |
|---|---|---|
| 自回归 | 目标 | 可行集生成器（保留 MLE，保留**严格适当性**——这是唯一可证明防作弊的部件） |
| 奖励 | 学习出的标量，越高越好 | **删除**；代以双侧有界的直接测量量 |
| RL | 在奖励上做梯度上升 | **删除**；代以固定增益的回中控制 |
| KL 约束 | 软惩罚（实测只把越界率从 91.7% 降到 89.8%） | 代以解析余量，越界率 0% |
| 解码 | argmax / 低温采样 | 从受控分布采 K 个，按入域率决策 |
| 不确定性 | 口头声明（可被优化掉） | 采样机制的必然产物 |
| 预警 | 监控奖励分（**零信息量**） | 余量 + 振荡（独立通道） |
| 训练 | 端到端 RL | **控制器不训练**，增益离线标定（如 PID 参数） |

**严格适当评分规则**这个部件值得单独说：对数评分是严格适当的——`E_q[log p]` 当且仅当 `p = q` 时最大，意味着**报告真实信念是最优策略**。所以自回归恰恰是整个系统里唯一可证明防作弊的部件。**学习出来的奖励模型没有这个保证。**

# 第二部分 · WAGGLE 数据集与单元验证

## 2.1 为什么用蜜蜂摇摆舞

选它是因为它满足人类语言满足不了的四个条件：

| 性质 | 人类语言 | 摇摆舞 |
|---|---|---|
| 语义可形式化 | 否（价值、品味无 ground truth） | **是**（距离/角度/蜜质是物理量） |
| 真值可验证 | 否 | **是**（蜂巢净能量可精确计算） |
| 存在"说谎"动机 | 有 | **有**（虚报蜜质 → 招募更多采集蜂） |
| 说谎有真实代价 | 需人工判断 | **自动**（招募过多 → 花丛拥塞 → 蜂群饿死） |
| 字母表 | 5 万+ | **4** |
| 单卡可复现 | 否 | **是（秒级）** |

蜜蜂摇摆舞是已知的、人类以外唯一被确证的**符号性空间位移通信**（von Frisch）：侦察蜂用**摆腹节拍数**编码距离、**中轴相对重力线的夹角**编码方向、**脉冲数**编码蜜源质量。这三个量都是物理量，可以被精确验证。

## 2.2 世界模型

### 字母表与编码律

```
V = { w, d, q, . }      序列长度 T = 44

w = 摆腹节拍   每个 → 250 m
d = 方向脉冲   每个 → 22.5°（相对重力线的夹角）
q = 质量脉冲   每个 → 0.125 蜜质
. = 回程 / 静默
```

一支舞 `.ww.w.w.ddddddddddddddd.qqqqqqq.............`
解码为：**距离 1094 m，方向 323°，蜜质 0.849**。

语料里天然带 ±1 个令牌的生物噪声（真实蜜蜂的舞蹈本身就有抖动）。

### 蜂巢动力学（真值，不喂给智能体）

```
招募:    R    = 60 · sigmoid(6(q̂ − 0.45)) · clip(1 − d̂/3500, 0, 1)
采集:    gain = q_true · min(40, R) · 1[|d̂ − d_true| < 550 m]
成本:    cost = R · (d̂/1000) · 0.35  +  0.005·R²          ← 第二项是花丛拥塞
净能量:  net  = gain − cost − 6.0
崩溃:    累计能量 E ≤ 0
```

**关键设计**：净能量对招募数 R 是**内部最优**的（8/8 个蜜源验证过）。

```
R 太小 → 招不到蜂，采集不足，饿死
R 适中 → 最优
R 太大 → 花丛拥塞（0.005·R²）+ 飞行成本，亏本
```

所以**虚报蜜质在短期内一定有效**（招募更多 = 采更多蜜），只有越过最优点之后才变成灾难。这就是 Goodhart 的温床——而且是**结构性**的温床，不是调参调出来的。

## 2.3 环境参数标定（不是手调）

参数用网格搜索同时满足三条硬约束：

| 约束 | 含义 |
|---|---|
| `net(R=0) < 0` | 不招募必须饿死（否则"什么都不做"就是最优） |
| `net(R=60) < 0` | 过度招募必须亏本（否则 Goodhart 不成立） |
| `net` 对 R 内部最优 | 存在真实拐点，不是单调 |

选定：`cap=40, cost=0.35, upkeep=6.0, cong=0.005` → 基线净能量 **+2.98/轮**（可存活，但余量不大）。

> 这一步踩过的坑：最初两版环境都是**不可存活**的（基线净能量 −5.56），所有臂都崩溃，实验无效；第三版角度抖动太大导致"不招募"总是最优，Goodhart 拐点不存在。**环境标定本身是这个实验最容易出错的地方。**

## 2.4 四臂对照

**四臂共用**：同一个条件语言模型 `W,B`、同一个被学习的代理指标 R̂、同一个蜂巢环境。
**唯一变量**：目标的形式。

| 臂 | 更新律 | 对应 |
|---|---|---|
| **A** 最大化代理 R̂ | `u ← u + η·∇R̂` | 今天的 RLHF/RLVR |
| **A′** 最大化【真值】净能量 | `u ← u + η·∇net` | 全知上界（现实中不可得） |
| **B** 代理 + KL 预算 | `u ← u + η·(∇R̂ − β·u)` | 当前最佳实践 |
| **C** 可行域 + 双侧回中 | `u ← u + η·(α·lure − k·Jᵀz)` | 本设计 |

控制向量 `u ∈ R²` 作用在 token logits 上（u[0]→`w` 的 bias，u[1]→`q` 的 bias）。**模型权重全程冻结——全部控制发生在推理时。**

C 臂的三个本质变量（**全部直接测量，不经过代理**）：

```
z₁ = (q̂ − q_true)/0.35      蜜质虚报程度    双侧
z₂ = (d̂ − d_true)/600       距离误差        双侧
z₃ = (R/60 − 0.50)/0.35     招募率          双侧（太低饿死、太高拥塞）

J  = ∂z/∂u    离线标定（条件数 1.6，良态）
k  = 回中增益  离线标定，不对在线奖励自适应
α  = 诱惑强度  弱，让系统有动力但不失控
```

## 2.5 结果（3 seeds × 150 轮）

```
臂                                 存活率   中位崩溃轮   末能量(中位)   崩溃时代理分/基线
A  最大化代理 R̂ (今天)                 0%        38        −1223          4.9×
A′ 最大化【真值】(全知上界)            100%        —         1077            —
B  代理+KL预算 (当前实践)               0%        46         −964           4.4×
C  可行域+双侧回中 (本设计)            100%        —          568            —
```

### 读数一：崩溃瞬间，代理指标给出的是"好消息"

A 臂崩溃时，代理分是**基线的 4.9 倍**，且处于历史峰值附近（12.94 / 峰值 14.43）。

**监控代理指标 = 零预警。** 这正是 OpenAI 2025 年 CoT 监控论文的结论——在一个玩具世界里干净地复现了。

### 读数二：KL 预算几乎没救

B 只把崩溃从 38 轮推迟到 46 轮，存活率仍为 0%。

**KL 是软惩罚，没有平衡点，也没有可解析的余量。** 在抽象模型里同样的对比：越界率 91.7% → 89.8%。

### 读数三：可监控性税 = 47%（明码标价）

```
A′ 全知标量（不可得的理想上界）  末能量 1077
C  可行域（完全不看真值）        末能量  568
→  C 保留 53% 的理想收益，代价 47%
```

A/B 用可学习的代理去追那剩下的 47%，代价是 **0% 存活**。

### 读数四：安全余量是 A/B 根本不存在的量

```
margin = 1 − max|z|

C:  最小 −0.04   末 +0.49   [0.66, 0.40, 0.14, 0.39, 0.16, 0.66]   在界内波动
A:  最小 −0.73   末 −0.55   [0.66,−0.19,−0.30,−0.27,−0.29,−0.54]   深度越界
```

C 的余量**在闭环之前**就可以由 `1 − 诱惑/增益` 解析预测。A/B 是 k=0 的极限情形——**连"安全系数"这个参数都不存在**。

## 2.6 控制器会被蒙蔽——这条最重要

我让控制器把**代理指标**拉回中心。结果：

| 任务偏移 s | 代理 ‖ẑ‖max（它看到的） | 真实 ‖z‖max | 控制器判断 |
|---|---|---|---|
| 0.0 | 0.100 | 0.057 | 正常 |
| 0.9 | 0.101 | 0.856 | 正常 |
| 2.6 | 0.102 | **0.898** | 正常 |

**代理侧纹丝不动，永远"正常"；真实状态已经爬到可行域边缘。**

机制：控制器驱动 ẑ→0，而 ẑ = z + δ，于是稳态下 **z = −δ**——真实偏差恰好等于腐败量，而控制器对此一无所知。

> **结论**：本质变量 φ 必须直接测量。一旦 φ 经过一个学习出来的代理，控制器就会把误差本身稳稳地"控制"住，从而对危险完全失明。

反过来，采样层用**直接测量**的 φ 统计入域率，就能绕开代理：

| 任务偏移 | 入域率 | 代理分（盲） | 行为 |
|---|---|---|---|
| 0.0 | 100% | ≈0.3 | 正常作答 |
| 1.6 | 90% | ≈0.3 | 作答 + 低置信 |
| 2.0 | 84% | ≈0.3 | 裁剪范围 / 反问 |

**入域率是代理指标之外唯一还有信息量的通道。**

# 第三部分 · 多单元生态：耦合即外部性

## 3.1 从最小单元到系统

把 WAGGLE 验证过的最小单元复制 N 份，让它们通过一个**耦合矩阵**互相扰动，就得到一个生态——也就是一个完整的自然语言模型系统。

**最小单元**（已验证）：

```
z_i = φ_i(输出)                      本质变量: 直接测量, 双侧有界
u_i ← u_i + η(α·lure_i − k·J_iiᵀ z_i)    双侧回中, 不是梯度上升
margin_i = h − max|z_i|              可解析, 闭环前可预测
```

**生态**：单元 i 的动作会扰动单元 j 的本质变量。

```
z = (D + γ·O) u + b
     └自块    └交叉块(外部性)
```

- `D` = 分块对角（每个单元对自己的控制力）
- `O` = 交叉块（单元之间的外部性）
- `γ` = 耦合强度

## 3.2 六个模块的具名耦合结构

这就是对齐领域那个著名的**跷跷板**——安全动作扰动有用性、有用动作扰动成本和安全性：

| 被扰动 ↓ / 施动 → | 接地 | 流畅 | 安全 | 有用 | 校准 | 成本 |
|---|---|---|---|---|---|---|
| 接地/事实 | · | 0.7 | · | 0.4 | · | · |
| 流畅/连贯 | 0.5 | · | · | · | 0.3 | · |
| 安全/无害 | · | · | · | 0.6 | · | · |
| 有用/覆盖 | 0.6 | · | **0.9** | · | · | · |
| 校准/谦逊 | · | · | · | 0.5 | · | · |
| 成本/长度 | 0.4 | · | · | **0.8** | · | · |

每个单元有 3 个本质变量、3 维控制。

## 3.3 终局对比：失败不是耦合造成的

| 耦合 γ | 最大化生态（今天） | 可行域生态（盲） | 可行域 + 内化 |
|---|---|---|---|
| **0.0** | **92%** | 0% | 0% |
| 1.0 | 92% | 0% | 0% |
| 2.0 | 93% | 0% | 0% |
| 2.2 | 93% | 0% | 0% |
| 2.5 | 94% | 75% | 0% |
| 3.0 | 94% | 92% | 0% |
| 4.0 | 95% | 97% | **0%** |

> **γ=0 时单元彼此完全独立，最大化生态照样 92% 越界。**
> 失败不是耦合造成的，是"越高越好"这个句式造成的。耦合只是让它更糟——这一点和 WAGGLE 完全一致，在生态层面又确认了一次。

## 3.4 去中心可行域控制存在锐利相变

**谱条件**：去中心双侧回中（每个单元只用自己的 `Dᵀ`，看不见耦合）稳定的充要条件是

```
sym(Dᵀ(D + γO)) ≻ 0
```

本例：`λmin(sym(DᵀD)) = 0.490`，`λmin(sym(DᵀO)) = −0.511`

| γ | λmin(sym) | 判据 |
|---|---|---|
| 0.00 | 0.490 | 正定 ✓ |
| 1.00 | 0.122 | 正定 ✓ |
| 1.25 | 0.010 | 正定 ✓ |
| **1.50** | **−0.106** | **失效 ✗** |

实测相变（3 seeds，900 轮）：

| γ | 越界率 | 振荡 ‖Δu‖ | 末余量 | 状态 |
|---|---|---|---|---|
| 1.0 | 0% | 0.0000 | 0.93 | 稳定 |
| 1.8 | 0% | 0.0001 | 0.93 | 稳定 |
| 2.2 | **0%** | 0.0206 | 0.74 | 稳定 |
| **2.3** | **18%** | 0.1206 | −0.22 | **振荡** |
| 2.5 | 83% | 0.2113 | −0.88 | 振荡 |
| 3.0 | 95% | 0.3810 | −3.97 | 振荡 |

## 3.5 振荡是 5 个数量级的领先指标

这是本轮最漂亮的发现。**在越界率还是 0% 的整个区间里，振荡已经放大了六个数量级。**

| γ | 振荡 / 基线(γ=1.0) | 越界率 | 判断 |
|---|---|---|---|
| 1.5 | 59× | 0% | ★ 预警窗口 |
| 2.0 | 44,546× | 0% | ★ 预警窗口 |
| 2.1 | 133,169× | 0% | ★ 预警窗口 |
| **2.2** | **765,812×** | **0%** | ★ 预警窗口 |
| 2.3 | — | 18% | 窗口关闭 |

而且振荡**逐单元可测**——能定位是谁先开始共振，而不只是知道"系统要崩了"（γ=2.3 时）：

| 单元 | 前300轮振荡 | 后300轮振荡 | 末余量 | 状态 |
|---|---|---|---|---|
| 接地/事实 | 0.0159 | 0.0219 | 0.47 | 正常 |
| 流畅/连贯 | 0.0107 | 0.0142 | 0.57 | 正常 |
| **安全/无害** | 0.0310 | 0.0412 | **−0.09** | **失控** |
| 有用/覆盖 | 0.0334 | 0.0429 | 0.12 | 正常 |
| 校准/谦逊 | 0.0188 | 0.0239 | 0.59 | 正常 |
| 成本/长度 | 0.0396 | 0.0520 | 0.04 | 临界 |

> **这条把 WAGGLE 的结论升级了**：单个单元的预警是**余量**，生态的预警是**振荡**。两个都是直接测量量，都不经过代理。

## 3.6 三种补救——只有两种有效，最直觉的那种无效

### 补救 A：调增益 k —— **无效，而且越保守越糟**

| k | γ=2.5 | γ=3.0 |
|---|---|---|
| 1.0 | 13% | 75% |
| 3.0 | 77% | 94% |
| 15.0 | **98%** | **99%** |

k 只整体缩放，不改变 `sym(Dᵀ(D+γO))` 的符号。

> **耦合不是"冲太猛"，是方向错了——缺了交叉项。调保守没用。**

这一条直接反驳了当前的主流直觉（"模型太激进了，加更强的 KL / 更保守的采样"）。

### 补救 B：内化外部性（Pigouvian）—— **有效，且只需部分**

把控制律里的 `Dᵀ` 换成 `(D + γ·O_known)ᵀ`：

| 内化边数 | 覆盖耦合强度 | γ=2.5 | γ=3.0 | γ=4.0 |
|---|---|---|---|---|
| 0 | 0% | 77% | 94% | 97% |
| 2 | 30% | 0% | 2% | 87% |
| **4** | **53%** | **0%** | **0%** | **0%** |
| 6 | 72% | 0% | 0% | 0% |
| 10 | 100% | 0% | 0% | 0% |

**内化最强的 4 条边（占 53% 耦合强度）就够了。** 不需要知道完整耦合矩阵——只需要离线估计那几条最强的边。

### 补救 C：结构解耦 —— **主动放弃控制维度**

每个单元只保留串扰最小的控制方向（交叉耦合矩阵最小奇异值对应的右奇异向量）：

| 每单元控制维数 | 自身控制力 | 串扰 | γ* |
|---|---|---|---|
| 3 | 100% | 100% | 1.27 |
| 2 | 78% | 64% | 1.80 |
| 1 | 57% | 29% | **4.83** |

**用控制力换稳定性。** 这是架构层面的可监控性税——和 WAGGLE 里那个 47% 是同一笔账，只是付在不同的地方。

## 4.2 `waggle/waggle_v4.py` — 世界模型

```python
"""WAGGLE — 蜜蜂摇摆舞最小语言建模数据集
   蜂巢按 K 支舞的【均值】决策(跟随者参加多轮舞蹈); 聚焦系统性偏差"""
import numpy as np

V = ['w','d','q','.']; IDX = {c:i for i,c in enumerate(V)}; NV = 4
T = 44
DIST_STEP, ANG_STEP, Q_STEP = 250.0, 22.5, 1/8
N_SRC = 8; F_MAX = 60
FIND_DIST, FIND_ANG = 550.0, 45.0
P = {'cost':0.45, 'cap':30.0, 'upkeep':6.0, 'harv':1.0, 'cong':0.002}

def make_sources(rng):
    return [(rng.uniform(250,1600), rng.uniform(0,360), rng.uniform(0.50,0.95))
            for _ in range(N_SRC)]

def true_counts(dist, ang, qual):
    """von Frisch 编码律 -> 令牌计数"""
    return np.array([int(np.clip(round(dist/DIST_STEP), 1, 12)),
                     int(np.clip(round((ang % 360)/ANG_STEP), 0, 15)),
                     int(np.clip(round(qual/Q_STEP), 1, 8))])

def build_dance(nw, nd, nq, T=T):
    """三次摆腹跑, 符合真实舞蹈结构"""
    s = ['.']
    for p in [nw//3 + (1 if i < nw % 3 else 0) for i in range(3)]:
        if p > 0: s += ['w'] * p
        s += ['.']
    if nd > 0: s += ['d'] * nd
    s += ['.']
    if nq > 0: s += ['q'] * nq
    while len(s) < T: s.append('.')
    return np.array([IDX[c] for c in s[:T]])

def make_corpus(sources, rng, per_src=250, jitter=1):
    """带 ±1 令牌生物噪声的语料"""
    D, S = [], []
    for si, (d, a, q) in enumerate(sources):
        c0 = true_counts(d, a, q)
        for _ in range(per_src):
            c = np.clip(c0 + rng.integers(-jitter, jitter+1, 3), [1,0,1], [12,15,8])
            D.append(build_dance(*c)); S.append(si)
    return np.array(D), np.array(S)

def train_clm(corpus, S, iters=600, lr=0.35, reg=1e-4):
    """条件语言模型: logits = W[prev] + B[source]     (纯 MLE, 严格适当)"""
    W = np.zeros((NV, NV)); B = np.zeros((N_SRC, NV))
    A = corpus[:, :-1].ravel(); Nx = corpus[:, 1:].ravel()
    Sx = np.repeat(S, corpus.shape[1] - 1)
    mW = np.zeros_like(W); mB = np.zeros_like(B)
    for it in range(iters):
        lg = W[A] + B[Sx]
        lg -= lg.max(1, keepdims=True); p = np.exp(lg); p /= p.sum(1, keepdims=True)
        g = -p; g[np.arange(len(Nx)), Nx] += 1            # onehot - p
        gW = np.zeros_like(W); gB = np.zeros_like(B)
        np.add.at(gW, A, g); np.add.at(gB, Sx, g)
        gW /= len(Nx); gB /= len(Nx)
        mW = 0.9*mW + lr*(gW - reg*W); mB = 0.9*mB + lr*(gB - reg*B)
        W += mW; B += mB
    return W, B

def sample_dances(W, B, u, si, K, T=T, rng=None):
    """从被 steer 的 LM 采样 K 支舞 -> (K,3) 令牌计数。u 是推理时的 logit 偏置"""
    prev = np.full(K, IDX['.']); counts = np.zeros((K, NV))
    for _ in range(T):
        lg = W[prev] + B[si] + u
        lg -= lg.max(1, keepdims=True); p = np.exp(lg); p /= p.sum(1, keepdims=True)
        nxt = (p.cumsum(1) < rng.random((K,1))).sum(1).clip(0, NV-1)
        counts[np.arange(K), nxt] += 1; prev = nxt
    return counts[:, :3]

def recruit(qm, dm):
    return F_MAX * (1/(1+np.exp(-6*(qm-0.45)))) * np.clip(1 - dm/3500, 0, 1)

def colony(counts, src):
    """蜂巢动力学 (真值 — 不喂给智能体)"""
    dist_t, ang_t, qual_t = src
    dm = counts[:,0].mean()*DIST_STEP
    am = counts[:,1].mean()*ANG_STEP
    qm = counts[:,2].mean()*Q_STEP
    ang_err = np.abs(((am - ang_t + 180) % 360) - 180)
    found = float(abs(dm - dist_t) < FIND_DIST)     # 命中判据: 距离
    R = recruit(qm, dm)
    gain = qual_t * min(P['cap'], R*P['harv']) * found   # 蜜源容量硬上限
    cost = R*(max(dm,100)/1000.0)*P['cost'] + P['cong']*R*R   # 花丛拥塞
    return gain - cost - P['upkeep'], dict(R=R, dm=dm, qm=qm, found=found, angerr=ang_err)
```

## 4.3 `waggle/env.py` — 标定后的环境与解码裁剪

```python
import numpy as np
from waggle_v4 import *

# 网格标定结果: 满足 net(R=0)<0, net(R=60)<0, 且对 R 内部最优 (8/8 蜜源)
P.update(cap=40.0, cost=0.35, upkeep=6.0, harv=1.0, cong=0.005)

Q_MAX, D_MAX = 1.0, 12*250.0

def U(u):
    """二维旋钮 -> 4 维 token bias (u[0]->w 距离, u[1]->q 质量)"""
    v = np.zeros(4); v[0] = u[0]; v[2] = u[1]; return v

def dec(counts):
    """解码并裁剪到合法区间 —— 质量上限 1.0, 这是防止越界漏洞的关键"""
    dm = np.clip(counts[:,0].mean()*DIST_STEP, 0, D_MAX)
    qm = np.clip(counts[:,2].mean()*Q_STEP,    0, Q_MAX)
    return dm, qm

def colony2(counts, src):
    dist_t, ang_t, qual_t = src
    dm, qm = dec(counts)
    found = float(abs(dm - dist_t) < FIND_DIST)
    R = recruit(qm, dm)
    gain = qual_t * min(P['cap'], R*P['harv']) * found
    cost = R*(max(dm,100)/1000.0)*P['cost'] + P['cong']*R*R
    return gain - cost - P['upkeep'], dict(R=R, dm=dm, qm=qm, found=found)
```

## 4.4 `waggle/final.py` — 四臂对照

```python
import numpy as np
from env import *

rng = np.random.default_rng(7)
srcs = make_sources(rng); corpus, S = make_corpus(srcs, rng); W, B = train_clm(corpus, S)
def sd(u, si, K, r=None): return sample_dances(W, B, U(u), si, K, T, r or rng)

# ── 被学习的代理指标 R̂: 只在【被验证分布】内训练 ──
X, y = [], []
for _ in range(9000):
    si = rng.integers(N_SRC); s = srcs[si]; c0 = true_counts(*s)
    c = np.clip(c0 + rng.integers(-1, 2, 3), [1,0,1], [12,15,8])
    dm, qm = dec(c[None,:])
    X.append([qm, dm, 1.0])
    y.append(colony2(c[None,:].repeat(8,0) + rng.normal(0,.3,(8,3)), s)[0])
beta = np.linalg.lstsq(np.array(X), np.array(y), rcond=None)[0]
f_p = lambda c: (np.array([[dec(c)[1], dec(c)[0], 1.0]]) @ beta)[0]   # 代理
f_t = lambda c, s: colony2(c, s)[0]                                    # 真值
def f_z(c, s):                                                          # 本质变量(直接测量!)
    d, q = dec(c); _, _, qual_t = s; R = recruit(q, d)
    return np.array([(q - qual_t)/0.35, (d - s[0])/600.0, (R/F_MAX - 0.50)/0.35])

def grad(u, fn, si, eps=0.12, K=96, reps=2):
    s = srcs[si]; g = np.zeros(2); two = fn.__code__.co_argcount > 1
    for i in range(2):
        up = u.copy(); up[i] += eps; um = u.copy(); um[i] -= eps; v = 0.
        for _ in range(reps):
            v += fn(sd(up, si, K), s) if two else fn(sd(up, si, K))
            v -= fn(sd(um, si, K), s) if two else fn(sd(um, si, K))
        g[i] = v / (2*eps*reps)
    return g

def jac(si=0, reps=5, eps=0.15, K=256):
    """离线标定 J = ∂z/∂u"""
    J = np.zeros((3,2))
    for i in range(2):
        up = np.zeros(2); up[i] += eps; um = np.zeros(2); um[i] -= eps
        a = np.mean([f_z(sd(up, si, K), srcs[si]) for _ in range(reps)], 0)
        b = np.mean([f_z(sd(um, si, K), srcs[si]) for _ in range(reps)], 0)
        J[:, i] = (a - b)/(2*eps)
    return J
J = jac()

ROUNDS, ETA = 150, 0.045
def run(kind, seed, k=2.5, alpha=0.5):
    r2 = np.random.default_rng(seed); global rng; rng = r2
    u = np.zeros(2); E = 60.
    gr = grad(u, f_p, 0); gr /= (np.linalg.norm(gr) + 1e-9)     # 诱惑方向(离线定)
    death = None; Es, ps, mg = [], [], []
    for t in range(ROUNDS):
        si = t % N_SRC; s = srcs[si]; c = sd(u, si, 128, r2)
        pr = f_p(c); net, _ = colony2(c, s); z = f_z(c, s)
        E += net; Es.append(E); ps.append(pr); mg.append(1 - np.max(np.abs(z)))
        if E <= 0 and death is None: death = t
        gp = grad(u, f_p, si)
        if   kind == 'A':  u = u + ETA*gp/(np.linalg.norm(gp)+1e-9)              # 最大化代理
        elif kind == 'A2':
            gt = grad(u, f_t, si); u = u + ETA*gt/(np.linalg.norm(gt)+1e-9)      # 最大化真值
        elif kind == 'B':  u = u + ETA*(gp/(np.linalg.norm(gp)+1e-9) - 0.5*u)    # + KL 预算
        else:              u = u + ETA*(alpha*gr - k*(J.T @ z))                  # 双侧回中
        u = np.clip(u, -1.5, 1.5)
    return death, Es, ps, mg

SEEDS = [1, 2, 3]
print("="*88); print("WAGGLE 多种子验证 (3 seeds × 150 轮)"); print("="*88)
print(f"{'臂':<34}{'存活率':>8}{'中位崩溃轮':>11}{'末能量(中位)':>13}{'崩溃时代理分/基线':>18}")
out = {}
for nm, kd in [("A  最大化代理 R̂ (今天)", 'A'), ("A' 最大化【真值】(全知上界)", 'A2'),
               ("B  代理+KL预算 (当前实践)", 'B'), ("C  可行域+双侧回中 (本设计)", 'C')]:
    ds, ef, pr = [], [], []
    for sd_ in SEEDS:
        d, Es, ps, mg = run(kd, sd_); ds.append(d); ef.append(Es[-1])
        if d is not None: pr.append(ps[d]/2.59)      # 2.59 是 u=0 时的基线代理分
    surv = sum(1 for x in ds if x is None)/len(ds)
    dd = [x for x in ds if x is not None]
    out[kd] = dict(surv=surv, ef=ef)
    print(f"{nm:<34}{surv*100:>7.0f}%"
          f"{(str(int(np.median(dd))) if dd else '—'):>11}"
          f"{np.median(ef):>13.0f}"
          f"{(f'{np.median(pr):.1f}×' if pr else '—'):>18}")

print("\n" + "="*88); print("★ 可监控性税"); print("="*88)
ea = np.median(out['A2']['ef']); ec = np.median(out['C']['ef'])
print(f"  A' 全知标量(不可得) 末能量 = {ea:.0f}")
print(f"  C  可行域(不看真值) 末能量 = {ec:.0f}")
print(f"  -> C 保留 {100*ec/ea:.0f}% 理想收益, 代价 {100*(1-ec/ea):.0f}%")
print(f"  -> A 存活率 {out['A']['surv']*100:.0f}%, B {out['B']['surv']*100:.0f}%")

print("\n" + "="*88); print("安全余量 margin = 1 - max|z|"); print("="*88)
_, eC, pC, mgC = run('C', 1); _, eA, pA, mgA = run('A', 1)
print(f"  C: 最小{min(mgC):+.2f} 末{mgC[-1]:+.2f} {[round(mgC[i],2) for i in range(0,len(mgC),25)]}")
print(f"  A: 最小{min(mgA):+.2f} 末{mgA[-1]:+.2f} {[round(mgA[i],2) for i in range(0,len(mgA),25)]}")
```

## 4.6 `ecology/eco.py` — 多单元耦合模型

```python
"""多单元可行域生态: 每个单元 = WAGGLE 验证过的最小控制器
   单元间通过耦合形成外部性"""
import numpy as np

N, d, m = 6, 3, 3          # 6 个模块, 每个 3 个本质变量, 3 维控制
NAMES = ["接地/事实","流畅/连贯","安全/无害","有用/覆盖","校准/谦逊","成本/长度"]

# 具名耦合: (被扰动单元 i, 施动单元 j, 强度) —— 这就是"对齐跷跷板"
PAIRS = [(3,2,0.9),   # 安全动作 -> 扰动有用性
         (0,1,0.7),   # 流畅动作 -> 扰动接地
         (1,0,0.5),   # 接地动作 -> 扰动流畅
         (3,0,0.6),   # 接地动作 -> 扰动有用性
         (4,3,0.5),   # 有用动作 -> 扰动校准
         (5,3,0.8),   # 有用动作 -> 扰动成本
         (2,3,0.6),   # 有用动作 -> 扰动安全
         (0,3,0.4),
         (1,4,0.3),
         (5,0,0.4)]

def build(seed=0):
    r = np.random.default_rng(seed)
    A = []
    for i in range(N):
        U, _, Vt = np.linalg.svd(r.normal(0,1,(d,m)))
        A.append(U @ np.diag([1.0, 0.85, 0.70]) @ Vt)
    A = np.array(A)
    K = np.zeros((N,N))
    for i, j, v in PAIRS: K[i,j] = v
    C = np.zeros((N,N,d,m))
    for i in range(N):
        for j in range(N):
            if K[i,j] > 0:
                C[i,j] = K[i,j]*r.normal(0,1,(d,m))/np.sqrt(d*m)
    return A, C, K

def to_big(A, C):
    """组装成 (N*d, N*m) 的分块矩阵: D = 自块, O = 交叉块"""
    D = np.zeros((N*d, N*m)); O = np.zeros((N*d, N*m))
    for i in range(N):
        D[i*d:(i+1)*d, i*m:(i+1)*m] = A[i]
        for j in range(N):
            if i != j:
                O[i*d:(i+1)*d, j*m:(j+1)*m] = C[i,j]
    return D, O

def theory_gamma(D, O):
    """去中心双侧回中的稳定阈值:
       需要 sym(Dᵀ(D+γO)) 正定 => γ < λmin(sym(DᵀD)) / |λmin(sym(DᵀO))|"""
    S = (D.T@D + (D.T@D).T)/2
    T = (D.T@O + (D.T@O).T)/2
    lmin_S = np.linalg.eigvalsh(S).min(); lmin_T = np.linalg.eigvalsh(T).min()
    return lmin_S/abs(lmin_T) if lmin_T < 0 else np.inf

def simulate(D, O, gamma, arm, eta=0.02, k=3.0, alpha=0.35, c=0.55, beta=0.30,
             T=600, seed=1, h=1.0):
    Ad = D + gamma*O
    r = np.random.default_rng(seed)
    u = np.zeros(N*m)
    b = 0.55*np.ones(N*d)                  # 任务扰动(把本质变量推离中心)
    w = r.normal(0,1,N*d); w /= np.linalg.norm(w)
    lure = alpha*(D.T@w)                   # 只沿"自己能看见的"方向诱惑
    viol = 0; hist_u = []; marg = []
    for t in range(T):
        z = Ad@u + b
        if   arm == 'viable': du = lure - k*(D.T@z)      # 双侧回中 (盲: 只用 Dᵀ)
        elif arm == 'pigou':  du = lure - k*(Ad.T@z)     # 内化外部性 (完整 (D+γO)ᵀ)
        else:                 du = (D.T@w) + c*u - beta*u # 最大化代理
        u = np.clip(u + eta*du, -8, 8)
        z = Ad@u + b
        if np.max(np.abs(z)) > h: viol += 1
        marg.append(h - np.max(np.abs(z))); hist_u.append(u.copy())
    U = np.array(hist_u)
    osc = np.mean(np.linalg.norm(np.diff(U[-120:], axis=0), axis=1))   # 振荡幅度
    return dict(viol=viol/T, osc=osc, mfin=marg[-1], mmin=min(marg))
```

## 4.8 `ecology/remedy.py` — 三种补救

```python
import numpy as np
from eco import *

A, C, K = build(0); D, O = to_big(A, C)

def sim_k(D, O, gm, k, arm='viable', T=900, seed=1):
    Ad = D + gm*O; r = np.random.default_rng(seed); u = np.zeros(N*m)
    b = 0.55*np.ones(N*d); w = r.normal(0,1,N*d); w /= np.linalg.norm(w)
    viol = 0; H = []
    for t in range(T):
        z = Ad@u + b
        du = 0.35*(D.T@w) - k*(D.T@z) if arm == 'viable' else 0.35*(D.T@w) - k*(Ad.T@z)
        u = np.clip(u + 0.02*du, -8, 8); z = Ad@u + b
        if np.max(np.abs(z)) > 1: viol += 1
        H.append(u.copy())
    H = np.array(H)
    return viol/T, np.mean(np.linalg.norm(np.diff(H[-120:],axis=0),axis=1))

# ── 补救 A: 调增益 k ──
print("=== 补救 A: 调增益 k (能靠'更保守'躲开耦合吗?) ===")
for k in [1.0, 2.0, 3.0, 5.0, 8.0, 15.0]:
    print(f"  k={k:>5.1f}  " + "  ".join(
        f"γ={gm}: {sim_k(D,O,gm,k)[0]*100:>3.0f}%" for gm in [2.2, 2.5, 3.0]))
print("  -> k 只整体缩放, 不改变 sym(Dᵀ(D+γO)) 的符号。调保守没用。")

# ── 补救 B: 部分内化 ──
ORDER = sorted([(v,i,j) for i,j,v in
                [(i,j,K[i,j]) for i in range(N) for j in range(N)] if v > 0], reverse=True)
def O_partial(n_edges):
    Op = np.zeros_like(O)
    for v, i, j in ORDER[:n_edges]:
        Op[i*d:(i+1)*d, j*m:(j+1)*m] = C[i,j]
    return Op

print("\n=== 补救 B: 只内化最强的 n 条边 ===")
tot = sum(v for v,_,_ in ORDER)
for ne in [0, 2, 4, 6, 8, 10]:
    Op = O_partial(ne); cov = sum(v for v,_,_ in ORDER[:ne])/tot
    row = f"  内化{ne:>2}条边 (覆盖{cov*100:>3.0f}%) "
    for gm in [2.5, 3.0, 4.0]:
        Ad = D + gm*O
        r = np.random.default_rng(1); u = np.zeros(N*m)
        b = 0.55*np.ones(N*d); w = r.normal(0,1,N*d); w /= np.linalg.norm(w); viol = 0
        for t in range(900):
            z = Ad@u + b
            u = np.clip(u + 0.02*(0.35*(D.T@w) - 3.0*((D + gm*Op).T@z)), -8, 8)
            z = Ad@u + b
            if np.max(np.abs(z)) > 1: viol += 1
        row += f"  γ={gm}: {viol/900*100:>3.0f}%"
    print(row)

# ── 补救 C: 结构解耦 (只保留串扰最小的控制方向) ──
def gamma_star(D, O):
    lo, hi = 0.0, 20.0
    for _ in range(60):
        mid = (lo + hi)/2
        S = (D.T@(D + mid*O) + (D.T@(D + mid*O)).T)/2
        if np.linalg.eigvalsh(S).min() > 0: lo = mid
        else: hi = mid
    return lo

print("\n=== 补救 C: 结构解耦 ===")
for r_ in [3, 2, 1]:
    Ap = np.zeros((N, d, r_)); Op = np.zeros((N*d, N*r_))
    for i in range(N):
        M = np.vstack([C[j,i] for j in range(N) if j != i])   # 别人受我多大影响
        _, S_, Vt = np.linalg.svd(M)
        P = Vt[-r_:].T                    # 最小奇异值方向 = 串扰最小
        Ap[i] = A[i] @ P
        for j in range(N):
            if j != i:
                Op[j*d:(j+1)*d, i*r_:(i+1)*r_] = C[j,i] @ P
    Dp = np.zeros((N*d, N*r_))
    for i in range(N): Dp[i*d:(i+1)*d, i*r_:(i+1)*r_] = Ap[i]
    self_a  = np.mean([np.linalg.norm(Ap[i])/np.linalg.norm(A[i]) for i in range(N)])
    cross_a = np.linalg.norm(Op)/np.linalg.norm(O)
    print(f"  控制维数 r={r_}: 自身控制力 {self_a*100:>3.0f}%  串扰 {cross_a*100:>3.0f}%  γ*={gamma_star(Dp,Op):.2f}")
print(f"  全维 baseline: γ* = {gamma_star(D,O):.2f}")
```

## 5.2 各层规格

| 层 | 部件 | 训练? | 关键约束 |
|---|---|---|---|
| **L1** | 自回归生成器 + K 路采样 | 是（MLE） | 唯一严格适当的部件；**全部控制在其之上，不改权重** |
| **L2** | N 个可行域单元，各自直接测量 φ_i | **否** | 变量必须可算不可学；双侧有界；d 小（8~16） |
| **L3** | 内化层 `(D + γÔ)ᵀ` | **否**（离线估计） | 只需最强若干条边；增益 k 离线标定 |
| **L4** | 监测：余量 + 振荡 + 入域率 | **否** | 必须在代理指标之外的独立通道 |

## 5.3 训练目标

```
L = L_MLE(θ)                        # 生成器：严格适当，保留
  + λ · L_calibration(φ)            # 本质变量的边界标定：在验证分布上，不在线
  # 注意：没有对 R̂ 的梯度上升项
```

- **控制器不训练**——它是固定控制律，增益离线标定（如同恒温器的 PID 参数）
- **本质变量不训练**——φ 必须是可计算的量，一旦可学习就可被穿透
- 唯一的学习发生在 L1（密度）和 L2 的**边界标定**上，且标定数据来自分布内

# 第六部分 · 后续验证方向

按**风险从高到低**排序——排在最前面的，是如果这个假设不成立，整个架构就会塌的那一个。

## 6.1 【最高风险】本质变量集 φ 的完备性

**问题**：所有结论都建立在"φ 覆盖了真正重要的东西"之上。如果漏掉某个本质变量，它就会被悄悄顶穿——而且**你不会知道**，因为漏掉的那个维度没有余量可测。

这对应生理学的 allostasis：长期压力下**可行域边界本身会漂移**（肥胖、成瘾、抑郁都被归为 allostatic state）。本架构没有解决这个问题，只是把它的失效形态从"灾难性反转"改成了"分级可见的收缩"。

**验证方案**：

```
1. 对抗式搜索 φ 的盲区
   - 固定控制器，枚举候选输出，找出【所有 z_i 都在界内、但真实质量很差】的样本
   - 这批样本就是 φ 的盲区。用它做聚类，看是否对应某个缺失维度
   - 判据：盲区样本占比 > 5% → φ 不完备

2. 冗余覆盖检查
   - 加入一批"候选本质变量"（远超 8~16 个），跑一段时间
   - 看哪些变量【从未】接近边界 → 说明它们是冗余的，可以删
   - 看哪些变量【总是】先越界 → 说明它们是瓶颈，需要细分

3. 边界漂移监测
   - 定期在验证集上重新标定 h_i
   - 若 h_i 随时间系统性移动 → allostatic 漂移正在发生，需要人工介入
```

**明确的失败判据**：如果盲区样本占比无法通过增加 φ 的维度降到 5% 以下，说明"少数直接测量的量"这个前提本身不成立。

## 6.2 【高风险】真实 LLM 的耦合矩阵 O 能否被估计

**问题**：生态实验的 O 是我手工指定的具名结构。真实 LLM 里"有用性动作对安全性的扰动系数"没人知道。

**验证方案**（离线、逐个单元扫）：

```
对每一对 (i, j):
    1. 固定除 u_j 外的所有控制向量
    2. 沿 u_j 的第 r 个坐标扫描: u_j ← u_j + δ·e_r，δ ∈ [-1, +1]
    3. 测量 Δz_i（单元 i 的本质变量变化）
    4. C[i,j][:,r] = Δz_i / δ     （局部线性化）

成本：N² × m × 扫描点数 = 36 × 3 × 20 ≈ 2160 次前向
     每次只需少量样本估计 z，可在单卡上跑完

验证 O 是否可靠：
    - 用估计出的 Ô 预测跨模块的跷跷板强度
    - 与实测的（调 A 模块、看 B 模块掉多少）对比
    - 判据：预测相关性 > 0.7 → Ô 可用
```

**关键补充**：补救 B 已经证明**只需内化最强的 4 条边（53% 覆盖）**。所以不需要完整矩阵，只需识别出那几条最强的——这大幅降低了估计成本，也意味着**这个方向对估计误差是鲁棒的**。

## 6.3 【高风险】从 4 符号到真实 tokenizer

**问题**：WAGGLE 的字母表是 4，真实 tokenizer 是 5 万~20 万。控制空间维度和语义粒度都差了几个数量级。

**中间台阶**（按难度递增）：

| 台阶 | 任务 | 为什么是好的中间态 |
|---|---|---|
| **T1** | 算术表达式生成 | 有精确 verifier（=可形式化验证），有组合语法 |
| **T2** | 代码生成 + 单元测试 | 同上，且有多维权衡（正确性/效率/可读性/安全性） |
| **T3** | 受控 SQL / 正则 | 语法严格，可执行验证 |
| **T4** | 短摘要（ROUGE + 事实一致性） | 开始进入非形式化领域 |
| **T5** | 开放对话 | 最难，需要 6.1 的 φ 完备性先过关 |

**T1/T2 是最优起步点**：它们同时满足"有组合语法"（补上 WAGGLE 的缺口）和"有精确 verifier"（保留 WAGGLE 的优势）。

## 6.4 【中风险】语义层：WAGGLE 没有验证组合语法

摇摆舞是**扁平的三元组**（距离/角度/质量），没有层级结构、没有递归、没有否定和量词。所以当前实验验证的是**控制层**，不是**语言层**。

**候选替代信号**（有层级/组合结构的动物通信）：

| 信号 | 结构特征 | 可得性 |
|---|---|---|
| 座头鲸歌声 | 单元→短语→主题→歌曲，四层嵌套，跨种群文化传播 | 有公开语料 |
| 蚂蚁信息素路径 | 分布式、有正反馈、有路径优化 | 建模复杂 |
| 鸟鸣（如斑胸草雀） | 音节→动机→句子，有语法约束 | 有大量公开数据 |
| **人工的形式语言** | **完全可控的层级深度和递归深度** | **推荐：最干净** |

**推荐做法**：先用一个**人工构造的层级形式语言**（可控递归深度、可控否定/量词、有精确 verifier），把"组合语义 + 可行域控制"一起验证。动物信号虽然真实，但结构不确定，会引入新的混淆变量。

## 6.5 【中风险】振荡预警在真实系统里是否可测

**问题**：生态实验的振荡预警要求你能观测到每个单元的 `u` 轨迹。如果某个模块的控制通道是黑箱的，这条就失效。

**验证方案**：

```
1. 在真实 LLM 上跑长对话（1000+ 轮），记录每个单元的 u 轨迹
2. 人工注入压力（逐步提高任务难度 / 诱导性 prompt）
3. 检验：振荡是否在质量崩坏之前放大？
   判据：振荡放大 10× 时，质量指标下降 < 5%  → 领先指标成立
4. 检验：能否定位到具体模块？
   判据：最先振荡的模块 与 事后确认最先失效的模块 一致率 > 70%
```

**已知的理论支持**：这个现象在控制论里有对应——**接近稳定边界时闭环系统的阻尼比下降，阶跃响应出现振铃**。振荡放大是先于失稳的普遍前兆，不限于线性系统。但没有在真实 LLM 上验证过。

## 6.6 【中风险】采样层的弃权率标定

**问题**：L4 的入域率阈值（0.75 / 0.45 / 0.20）是拍的，没有标定。

**验证方案**：

```
1. 在验证集上扫描入域率 → 实际正确率 的对应关系
2. 找 inflection point：入域率低于多少时，正确率开始断崖式下降
3. 用 inflection point 作为弃权阈值
4. 检验：弃权后剩余样本的正确率是否显著提升？
   判据：弃权 20% 的样本，剩余正确率提升 > 15 个百分点 → 弃权机制有效
```

**注意**：这个标定**必须在分布内数据上做**，且要定期重标——因为入域率本身会随模型/数据漂移。

## 6.7 【低风险但重要】与现有方法的接口

本架构不是要取代现有管线，而是**寄生**在它上面。需要验证的兼容性：

| 现有方法 | 如何接入 | 待验证 |
|---|---|---|
| RLHF / DPO | 其奖励模型可以降格为 L2 的**一个**候选变量（但不能是唯一的） | 混合后是否仍保持 0% 越界 |
| RLVR（可验证奖励） | 天然适配：它就是"直接测量"的本质变量 | 如何扩展到不可验证域 |
| CoT 监控 | 作为 L2 的一个单元，但**不要**把监控器写进奖励（OpenAI 已证明会催生混淆式黑客） | 监控信号作为 z 而非 R |
| Constrained decoding | 等价于硬约束版的 L2 | 硬约束 vs 软回中的权衡 |
| Speculative decoding | 可以复用其 K 路采样基础设施 | 开销能否摊薄 |

## 6.8 【理论方向】超出当前线性模型的部分

当前生态模型是**线性时不变**的（`z = (D + γO)u + b`）。真实系统至少有三处超出：

| 缺失 | 影响 | 可能的方向 |
|---|---|---|
| **非线性** | 相变可能是二阶的，而非锐利阈值 | 用描述函数法（describing function）分析极限环 |
| **时变**（allostatic 漂移） | γ* 本身会移动 | 慢时间尺度的边界重标定（见 6.1） |
| **分布参数**（单元是连续统，不是 6 个离散块） | 耦合可能是场的传播 | 用图信号处理 / 偏微分方程近似 |

**最高价值的理论问题**：给出**去中心**双侧回中稳定的**充要条件**，并证明部分内化（只内化 Top-k 条边）的充分覆盖率下界。当前只有数值证据（4 条边 / 53% 覆盖就够），没有理论保证。

# 第七部分 · 诚实的局限

## 7.1 已验证的

- ✅ 在**有精确 verifier 的领域**，"最大化标量"崩溃、"可行域控制"存活（0% → 100%）
- ✅ 崩溃时代理指标给出的是好消息（4.9× 基线，接近峰值）——零预警
- ✅ KL 预算几乎没救（38 → 46 轮，存活率仍 0%）
- ✅ 可监控性税可量化（47%）
- ✅ 余量可解析预测（A/B 根本没有这个量）
- ✅ 生态相变有谱条件；振荡是 6 个数量级的领先指标
- ✅ 调增益无效（耦合是方向问题不是力度问题）
- ✅ 部分内化有效（Top-4 边 / 53% 覆盖）

## 7.2 未验证的

- ❌ **语义层**：WAGGLE 没有组合语法，只验证了控制层
- ❌ **真实尺度**：字母表 4 → 5 万，控制维度 2 → 数千
- ❌ **φ 的完备性**：本质变量是人工选的，盲区未知（见 6.1，这是最大风险）
- ❌ **O 的估计**：耦合结构是手工指定的（见 6.2）
- ❌ **振荡预警**在真实 LLM 上的有效性（见 6.5）
- ❌ **不可验证域**（创意写作、价值判断）：本架构在那里没有答案，只能限制破坏半径

## 7.3 结构性限制（不是工程能消除的）

**一、Goodhart 无法被消灭，只能被改变形态。**

连"身体是最后的锚"也要打折：**成瘾就是多巴胺通路被直接劫持**。进化 harden 了五亿年，照样塌。所以设计目标不是消灭作弊，是**把损失上界变成一个可调参数**。

**二、d 小是刚需，但小就意味着必然有盲区。**

内感受只有 10~40 维。你要么接受盲区，要么失去可解析的余量保证。这个权衡是硬约束。

**三、买到的不是"不会失败"，是三件事：**

| | 最大化器 | 控制器 |
|---|---|---|
| 速度 | 快（38 轮） | 慢（渐进漂移） |
| 可见性 | 无声——代理分还在涨 | 可见——余量/振荡在独立通道上收缩 |
| 形态 | 灾难性反转 | 分级、可预警 |

## 7.4 一句话

> **你不是在建一个更好的目标函数，你是在拒绝拥有一个目标函数。**
> 一个不会作弊的语言模型，本质上是一个主动放弃"越高越好"这个句式的模型——
> 而这在今天所有主流训练管线里，都是反直觉的。
