## 1. φ v0.2 修订（§6.1 的落实）

### 1.1 悬崖谓词必须显式进 φ

z 类连续变量的归一化半径必须与真值判据半径**一致**（本次事故：z2 半径 600 vs
found 550）。任何"-found 即灾难"的判据（命中/编译通过/单位测试/URL 有效）都
以二值谓词形式进 φ：`z4 = 2·1[found] − 1`（双侧有界 {−1,+1}，直接测量）。

### 1.2 上下文条件化（Context-Conditioned φ）

- 场景盈利位定标：z3 中心从全局常数（R=30）改为场景最优 R*(si)；
  连续变量半径对齐该场景的悬崖半径。
- 效果实测：盲区 11.06%→1.05%，闭环末能量 +543（oracle 差距的 30%），
  区域指标与闭环指标**同向改善**——两把尺子互相印证。
- 理论对应：即 §6.1 的 allostasis——边界本身是场景状态的函数。
  h_i = h_i(场景盈利位)，不再全局常数。

### 1.3 场景级弃权（L4 的新职责）

R* 都救不了的场景（net*≤0，如 S3/S6）**没有输出侧修复**。监测层新增场景级判据：
**可达净能量上界 net* ≤ 0 ⇒ 弃权该场景**（跳过源/拒绝任务），而非报告低余量。
实测：弃权 3 陷阱源后 C 臂末能量 568→+2117（2.6 倍于全源策略）。
对应 LM 场景：任务级可行性预判（无证据可查的幻觉题、无法编译的规格）——
**弃权是余量监测在场景粒度的自然延伸，不是新增机制。**

### 1.4 φ 测量的"提及≠使用"区分

prompt 作动器实验的污染：反模糊指令（引用了"可能/也许"二字）使 hedge 计数
0→1.33/百字。直接测量必须区分**使用与提及**（引号内/指令复述不计入），
否则指令本身成为测量旁路——与"本质变量不可学习"同理：**本质变量不可被
输入文本污染**。

## 2. 增益调度（对 §1.3 决策一的增补）

k 扫描实测（300 轮闭环，2~4 seeds）：

| φ 变体 | 最优 k | k 过阈的形态 |
|---|---|---|
| zA（宽尺度） | 2.5 | k=4 → −926 |
| zC（条件化·宽） | 0.5~2（平缓） | k=32 才钉死 |
| zB（条件化·紧） | **0.5** | k=4 即 −926，k≥8 钉死 −1211 |

**新规则：边界收紧 ⇒ 最优增益下调，且可调窗口变窄。**
操作化：每次 φ 重参数化（改尺度/改中心/加谓词）后必须重扫 k（离线，验证集）。
反例存档：Part 3 第一轮把 k=2.5 直接搬进 zB 得到完全相反的错误结论——
调参铁律不是官僚流程，是防止结论反转的护栏。

## 3. 作动器选择矩阵（对 §5.5 的增补）

四族作动器在 Spark-X2.5-1.7B 上的实测权限：

| 变量 | logit bias | activation steering (L14) | **prompt (system)** |
|---|---|---|---|
| len（表层） | ✅ 窗口[2,8] | ❌ | ⚠️ 被 token 上限饱和，短端 −10% |
| hedge（词汇统计） | ✅ 0.44→1.42/百字 | ❌（0→0.10） | ✅ **0→4.83/百字单调** |
| refuse（语义） | ❌ 死→崩 | ❌ | ✅ **0→0.67** |

结论：
1. **语义变量只有 prompt 作动器能动**——logit bias 止于词汇统计，steering 在
   非 residual-dominant 架构（本模型残差流范数 6.2）上失效。
2. 权限、耦合矩阵 O、崩坏阈值都是 **(变量, 作动器族) 的联合属性**——
   O 的估计必须绑定作动器族声明，否则没有意义。
3. 幅值自身有可行域（logit bias [2,8]、steering <5×残差范数、prompt 档位≤2）：
   **"可行域"哲学递归适用于作动器本身。**
4. prompt 作动器的档位曲线即增益曲线：档 1→2 的响应（2.08→4.83）表明
   指令强度是可微调的连续旋钮，可纳入 L2/L3 的控制律框架。

## 4. 协议修订（对 §6.2 的增补）

1. **权限曲线前置**：任何 O 估计前先扫 {0, ±小, ±中, ±大} 找工作窗口；
   文档的 ±δ 小信号差分在强 LM 上会得出 C≈0 假阴性（本次 ±0.5/±1 全死）。
2. **盲区统计条件化**：只在可救场景上计盲区；不可救场景单独报告并触发 §1.3 弃权。
3. **oracle 口径**：闭环对比必须同轮数累积（Part 3 第一轮 oracle 单轮/闭环 300 轮
   的口径事故）。
4. **steering 前置残差范数测量**：α 以 ×‖h‖ 计价，不以绝对值。
