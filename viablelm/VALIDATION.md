## 四、验证者补充（文档未写但应当写）

1. **线性谱条件偏保守**：解析 γ*=0.96 vs 实测相变 2.3，差距 2.4×。原因：simulate 里
   `u=clip(u,−8,8)` 的饱和非线性把越界的模态压住了。谱条件是"线性化不失稳"的
   保守充分条件，不是相变点。文档 §3.4 把两者并列呈现但未点破差距，复现者容易
   误读为理论失准——其实是理论保守。
2. **summary.py 的逐单元"放大倍数"列（1.3~1.4×）**与 README §3.5 表一致，但该表
   容易让人以为振荡放大是单元级的强信号；实际定位能力来自"相对排序 + 余量符号"，
   单元级放大倍数只有 1.3×。真正的 5~6 个数量级放大是**全局**振荡 ‖Δu‖。
3. **随机性极小**：3 seeds 全部结论一致，标准差可忽略——但这正说明环境是良性的
   （低噪声），真实 LLM 上 §6.5 的振荡预警可能远不如这里干净。
4. **make_dataset 可复现性**：`rng=default_rng(7)` 固定种子，语料 2000 条逐字节可复现。
