# 把原型放大到真实任务：语言建模与决策

> 目标：把 `二阶自觉_原型.py`（n=32，合成回归）迁移到真实任务，同时保留可验收性。
> 原则：**先保住可测量性，再谈规模**。原型之所以能给出因果证据，是因为 \(B\) 的 ground truth 可知、影子执行便宜、提案可枚举。放大时这三点会依次失守，必须有替代设计。

---

## 0. 先说什么会失守

原型能跑出 −30.9% vs +0.9%，依赖三个条件。放大时它们的失效顺序决定了迁移难度：

| 条件 | 原型 | 语言建模 | 决策（RL） |
|---|---|---|---|
| **B 的 ground truth 可知** | 是（合成 teacher） | **部分**（held-out 可得，但"真实有益"需长期定义） | **是**（真实环境回报） |
| **影子执行便宜** | 是（毫秒级） | **否**（全模型推理昂贵） | 中（世界模型 rollout 便宜，真机昂贵） |
| **提案可枚举** | 是（两个候选族） | **否**（参数空间巨大） | 部分（策略/世界模型结构化更新） |

> **关键判断**：决策任务是**更干净的检验场**——\(B\) 的锚定是**物理的**（环境动力学不由智能体修改），而语言建模中 \(B\) 是数据，必须靠**时间/历史锚定**（保留集产生于模型存在之前）。
> 建议路线：**先做决策任务验证因果链，再做语言建模验证规模**。

## 1. 组件映射表

### 1.1 语言建模

| 原型组件 | 语言建模对应物 | 具体选型 |
|---|---|---|
| \(\kappa_1\) 对象级 | DEQ-Transformer / 含隐式块的 LM | 主干 Transformer + 若干 DEQ 块（Anderson/Broyden 加速求解） |
| \(z^*=F(z^*,x)\) | 隐式层的固定点 | 序列级 DEQ 或每层独立固定点 |
| 收敛通道 \((\varepsilon_t,K_t,\rho_t)\) | 求解器诊断 | 每个 DEQ 块的残差范数、迭代次数、**幂迭代估计的谱半径** \(\hat\rho(J)\) |
| \(\kappa_2\) 元级 | 轻量监控网络 | 1–2 层 Transformer 或 MLP，读 \(\kappa_1\) 激活摘要 |

| \(R\) 修改定位 | 结构化提案 | LoRA 补丁 / 稀疏权重编辑 / 数据配比 / 超参（**不是全参数 rank-1**） |

| 证书 \(\pi\) | 保留集增量 + 不变量 + 回滚点 | 见 §2.3 |

### 1.2 决策 / RL

| 原型组件 | 决策对应物 | 具体选型 |
|---|---|---|
| \(\kappa_1\) 对象级 | 策略 \(\pi_\theta\) + 世界模型 \(w_\phi\) | Dreamer/MuZero 类架构 |

## 2. 保留可验收性的三个设计

### 2.1 不可约性：ANF 不可行，改用"廉价替代预测器"检验

ANF 测试在十亿参数上不可行（指数级），且在连续域失效（已实测）。替代方案：

> **可约性的操作性检验**：训练一个**廉价的替代预测器** \(\widetilde{\mathrm{Sim}}\)（线性化 / 低秩 / 闭式近似 / 少步展开），令其预测与 full \(\mathrm{Sim}\) 对比。
> - 若 \(\widetilde{\mathrm{Sim}}\) 在显著更低开销下达到相当精度 → **\(\mathrm{Sim}\) 可约，元级是伪的**；
> - 若廉价替代的误差随预测深度 \(k\) 快速发散（而 full \(\mathrm{Sim}\) 不发散） → **不可约性成立**。

具体指标：定义**深度-误差曲线** \(E_{\widetilde{}}(k)\) 与 \(E_{\mathrm{full}}(k)\)，报告比值 \(\rho_{\mathrm{eff}}(k)=E_{\widetilde{}}(k)/E_{\mathrm{full}}(k)\) 与开销比 \(\mathrm{cost}_{\mathrm{full}}/\mathrm{cost}_{\widetilde{}}\)。

**这与 D2 的精神一致**：不追求"证明不可约"，而是**证伪伪元级**——只要能找到便宜的等价预测器，元级就不成立。

### 2.2 σ_B 必须在线估计（原型调试的教训）

原型调试中出现过结果反转：\(\sigma_B\) 与真实改进量同量级时，外部验收反而劣于内部验收（虚假接受 10.3%）。

真实任务中的做法：

\[
\hat\sigma_B = \mathrm{std}\big(\text{bootstrap 重采样保留集得到的 } \Delta \big)
\]

**硬约束**：要求 \(\hat\sigma_B \ll |\mathbb{E}[\Delta_{\text{real}}]|\)。若不满足，**必须扩大保留集，或降低 \(\tau\) 的期望**——不能硬调 \(\tau\) 掩盖，那只会把虚假接受换成虚假拒绝。

### 2.3 证书的最小集（真实任务版）

```
cert = {
  delta_holdout      : 保留集指标增量 (bootstrap 置信区间, 非点估计)
  delta_downstream   : 下游 benchmark 增量
  invariants         : 形式化不变量保持 (如: 拒绝率不升、安全分类器分数不降)
  rollback_point     : 权重快照哈希
  scope              : 修改的模块范围 / 参数量占比
  cost_accounting    : 本次取证的计算开销
  touched_benchmark  : False   (硬约束)
}
```

## 3. 真实任务特有的新困难

### 3.1 提案空间爆炸

原型只需在两个候选族中选。真实系统中提案空间巨大，盲目搜索必失败（已由 §7.2 证明：盲目成功率 \(\propto 1/N_b\)）。

**对策**：提案生成必须**带方向先验**。三类可用来源：
1. **梯度对齐**（原型 honest 族的放大版）：用保留集梯度做低秩更新；
2. **失败案例聚类**：在 held-out 上定位失败模式，定向修补；
3. **元级对 ICO 全局结构的估计**：即设计规格中 \(R\) 的方向来源。

> 原型实测：**方向性决定成败，强度只决定频率**。放大后这条只会更极端（basin 数 \(N_b\) 更大）。

### 3.2 影子执行的成本

全模型在保留集上推理一次，代价可能是单次提案收益的若干倍。

**三层成本控制**：

| 层 | 做法 | 精度 | 成本 |
|---|---|---|---|
| L1 廉价筛选 | 世界模型/代理模型内 rollout，或小样本子集 | 低 | 极低 |
| L2 中等取证 | 保留集**子集** + bootstrap 置信区间 | 中 | 中 |
| L3 完整取证 | 全保留集 + 下游 benchmark | 高 | 高 |

**协议**：L1 否决 → 直接拒绝（不花 L2/L3）；L1 通过但 L2 置信区间跨零 → **拒绝**（等价于未知的保守处理，与环拓扑的"平局→未知"一致）；L2 明确为正 → L3 复核后 commit。

> 这个三级结构正好对应环拓扑的"可归因 vs 完全判定"二分：**L2 只做归因，L3 才做完全判定**。

### 3.3 时间尺度分离在真实训练中的含义

原型中 \(\eta_M/\eta_s\to0\)。真实训练中操作化为：

\[
\text{元级更新频率} \ll \text{对象级更新频率}
\]

建议：对象级每步更新；元级每 \(10^2\)–\(10^3\) 步更新；外部证书验证每 \(10^3\)–\(10^4\) 步，或**每次结构性修改**时触发。

**可检验预测**：若元级更新频率过高，应观测到 \(v_M\) 增大导致 \(r^*\) 扩大（原型已实测 \(v_M\) 与 \(\sigma_\xi\) 等效进入分子）。

### 3.4 多 basin 在真实景观中是常态

语言模型的 loss landscape 已知存在大量 basin 与 mode connectivity。故 §7 的结论直接适用：

- **不要**通过加大 \(B_M\)（提案幅度）来寻求跃迁；
- **要**提高方向正确率 \(\alpha_{\mathrm{dir}}\)；
- Lyapunov 对象必须是**分布层面**的自由能（basin 占据分布），不是单点 loss。

## 4. 分阶段路线

### 阶段 0：复现（1–2 周）

**目标**：在真实小规模数据上复现原型的因果对比（A vs B）。

- 任务：字符级/词级语言建模（如 WikiText-2、TinyStories）或经典控制/网格世界
- 模型：n=256–1024 的小 Transformer（含 1 个 DEQ 块）
- 保留集：时间上晚于训练数据的切片
- **验收**：A（外部证书验收）相对 B（内部验收）的真实 loss 差异方向一致，且虚假接受率显著更低

> 这一阶段**不追求性能**，只追求复现因果链。若阶段 0 无法复现，后续规模放大无意义。

### 阶段 1：决策任务（优先）

**理由**：\(B\) 的物理锚定最干净，\(\mathrm{Sim}\) 与 rollout 同构。

- 环境：具明确安全约束的任务（如带约束的连续控制、资源分配）
- 架构：世界模型 + 策略
- \(B\)：真实环境回报 + 不可修改的安全约束
- \(\mathrm{Sim}\)：世界模型 \(k\) 步 rollout
- **关键实验**：
  1. 方向性实验（定向提案 vs 盲目提案的成功率随"可选策略 basin 数"的变化）——在原型内实例化多 basin，补上对比报告中的 △
  2. \(v_M\) 与 \(\sigma_\xi\) 的等效性（扫元级更新频率）
  3. 可约性检验（§2.1）：训练廉价替代 rollout，看误差随 \(k\) 的发散速率

### 阶段 2：语言建模

- 模型：1B 级，含 DEQ 块
- \(B\)：held-out 语料（时间锚定）+ 下游 benchmark + 安全红线
- 提案：LoRA / 稀疏编辑 / 数据配比
- 影子执行：三级成本控制（§3.2）
- **关键实验**：
  1. 端到端：外部证书验收 vs 内部验收的下游 benchmark 差异
  2. 收敛自表征：DEQ 块残差/谱半径能否预测"该层是否收敛"（复现 D1）
  3. 分布式形状指纹（§7.4）：判断系统是被数据噪声驱动还是被元级干预推离

### 阶段 3：规模与长期运行

- 长期运行下的保留集老化问题（静态保留集会被逐步博弈 → 必须持续引入新数据）
- 多主体锚定（β 策略）的实例化
- 完备性不可得导致的长期停滞问题：接受率长期为 0 时的探索策略（原型 §7.3 已显示"零接受也可以是正确行为"，但长期需平衡）

## 5. 每个阶段的可比指标（保证跨规模可比）

为让阶段 0–3 的结果可以横向对比，固定以下五个指标：

| 指标 | 定义 | 原型基准值 |
|---|---|---|
| **\(G_{\mathrm{ext}}\)** | 外部验收相对内部验收的真实性能增益 | −30.9% vs +0.9% |
| **FA / FR** | 虚假接受率 / 虚假拒绝率 | 0.000 / — （τ=0）；0.0022 / 0.9853（τ=0.002） |
| **\(\alpha_{\mathrm{dir}}\)** | 提案方向正确率 | 定向 1.000 vs 盲目 0.000（\(N_b\ge6\)） |
| **\(\rho_{\mathrm{eff}}\)** | 元级可约性（廉价替代 / full Sim 的误差比） | ANF：\(\deg\equiv1\) vs \(2k-1\) |
| **probe** | 收敛自表征探针准确率 | 0.900（有通道）vs 0.567（无通道） |

**任何阶段若 \(G_{\mathrm{ext}}\) 消失或反号，优先检查 \(\sigma_B\)**（§2.2）——这是原型调试中实际踩过的坑。

## 6. 诚实清单：放大后仍无法检验的

| 项 | 原因 |
|---|---|
| \(B\) 的不可修改性 | 制度假设，不可实验验证；只能做权限攻防建模 |
| 完备性不可得的长期后果 | 需长期运行，短期实验观察不到 |
| 现象意识 | 不在射程内，且无已知桥梁 |
| 大规模下的不可约性严格证明 | ANF 不可行；只有 §2.1 的操作性证伪 |

---

## 7. 一句话路线

> **先在决策任务上验证因果链（\(B\) 物理锚定最干净、\(\mathrm{Sim}\) 与 rollout 同构），再在语言建模上验证规模；全程用五个固定指标保持跨规模可比；任何阶段 \(G_{\mathrm{ext}}\) 消失，先查 \(\sigma_B\)。**
