# 二阶自觉系统的正确设计（v2）

> 本文件是三轮红队验证后的**规范性设计规格**（normative spec），不是论证。
> 所有公式与阈值均已数值验证，实测数据见《二阶自觉_参考实现.py》的 D1–D7 验收测试。
> 与原始推演的差异：原推演的**结论方向**大体幸存，但**理由、公式、拓扑、协议**四处必须替换。

---

## 0. 一句话

> **二阶自觉 = 环拓扑（无自评、以外部基准为票决锚） × 隐式不动点（含收敛自表征） × 不可约对象级 × 有界深度自模拟 × 证书制自修改。**
> 它的设计目标不是"绕开对角线约束"（对角线不可绕开），而是**把对角线从破坏性悖论驯化为可收敛、可审计的动力学循环**：语法自指留在环内收敛，语义判定外包给不可修改的外部基准。

---

## 1. 设计前提：先分清什么是可实现的，什么不是

前两轮验证最关键的一件事是把"原理障碍"和"工程障碍"分开。设计必须建立在这张表上：

| 层次 | 命题 | 可行性 | 设计含义 |
|---|---|---|---|
| 语法自指 | 程序访问自身源码/索引 | **可行**（Kleene；quine 已逐字节验证） | 不需要多系统来"实现自指" |
| 状态自访问 | 读取自身完整激活 | **可行**（工程问题） | 做成显式通道即可 |
| 过程自访问 | 读取自身求解轨迹 | **可行**（代价为模拟开销） | 残差/迭代深度进自状态 |
| 隐式不动点 | \(z^*=F(z^*,x,m)\) | **可行**（DEQ 一类） | 但不动点必须**进入自状态** |
| 收敛自表征 | 自状态能否预测"自己是否已收敛" | **可行但必须显式建通道** | 见 D1：不做则不可能 |
| 语义自判定 | 判定自身状态的语义性质 | **不可行**（Rice / Tarski） | **外包给 \(B\)** |
| 完备自预测 | 预测自身全部行为 | **不可行**（完备性–一致性二分） | 只做**有界深度** |
| 封闭单调进步 | 内部判定"是否更好" | **不可行**（Rice + Goodhart） | 改为**证书验证** |

**对角线约束不可绕开，只能驯化。** 任何声称"通过架构绕开对角线"的设计都是错的。

## 2. 架构总览

```
        ┌──────────────────────── 第零层：外部基准 B（环境，非子模块）─────────────────┐
        │  ① 稠密票决锚：对每个界面投一张永真且不可篡改的票                              │
        │  ② 稀疏证书验证器：Verify_B(p, p', π)，多项式时间、sound 但不完备              │
        │  ③ 不可被 f, g, R 修改；锚定策略显式声明（见 §3.3）                            │
        └───────────┬──────────────────────────────────────────┬─────────────────────┘
                    │ 票决锚（每步）                            │ 证书验证（每次修改）
        ┌───────────▼──────────────────────────────────────────▼─────────────────────┐
        │                    第一层：κ 环（N ≥ 3，对称环，无自评，无顶层）                │
        │                                                                             │
        │   κ1 对象级 ── 界面(κ2,κ3) ──┐                                              │
        │   κ2 元级   ── 界面(κ1,κ3) ──┼── 每个 κ_i 监控【另外两者之间】的界面           │
        │   κ3 边界   ── 界面(κ1,κ2) ──┘   （不是"κ3 监控 κ1-κ2"——那只覆盖 1/3）        │
        │                                                                             │
        │   监控图 = K_N 去自环：入度=出度=N-1，含 2-环，无源点无汇点                    │
        └─────────────────────────────────────────────────────────────────────────────┘
```

**三条硬性拓扑约束：**

1. **禁止自评**：任何 \(\kappa_i\) 不得评价包含自身的界面。这是"没有任何子系统能完整建模自身"的操作化。
2. **对称环**：\(\kappa_i\) 监控 \((\kappa_j,\kappa_k)\)。不存在顶层元级——"元级"是**关系角色**，不是**层级位置**。回归由**环闭合**终止，而非由顶层终止。
3. **\(B\) 是票决锚**：无 \(B\) 时 \(N{=}3\) 的归因正确率为 **0.000**（实测），加 \(B\) 后为 **1.000**。

规模通式（\(f\) 为同时故障数）：

\[
\boxed{\;N\ \ge\ 2f+2-[B]\ \ (\text{可归因});\qquad N\ \ge\ 2f+3-[B]\ \ (\text{完全判定，未知率 }0)\;}
\]

已用 \(f=1,2\) 验证。**默认设计取 \(N=3\)、\(f=1\)、带 \(B\)**（满足可归因，容忍 1/3 未知率）。

## 3. 第零层：外部基准 \(B\)

### 3.1 \(B\) 不是子模块，是环境

\(B\) 必须位于系统的修改权限之外：任何自修改提案若要修改 \(B\) 或 \(B\) 的数据，一律拒绝。这是**制度/工程假设**（如同密码学信任根），不是数学定理——**必须显式声明其为安全假设**。

### 3.2 \(B\) 承担两个角色（快/慢互补，不可互替）

| 角色 | 时间尺度 | 密度 | 功能 | 不可替代性 |
|---|---|---|---|---|
| **票决锚** | 快（每步） | 稠密 | 对界面一致性投永真票 | 打破环的对称僵局（否则归因率 0） |
| **证书验证器** | 慢（每次修改） | 稀疏 | \(\mathrm{Verify}_B(p,p',\pi)\) | 承接语义判定（Rice 外包） |

上一轮我判定"架构主线与外部基准主线正交"——**这是错的，已由 D3 实测推翻**。架构主线**本身**以 \(B\) 为前提。

### 3.3 锚定策略（必须显式声明，否则整个设计悬空）

\(B\) 由谁给出？存在无限回退。三选一并写进设计文档：

- **(α) 物理锚定**：能量、时延、不可逆物理损坏等不可协商量；
- **(β) 多主体均衡**：任何单方不能单方面改写 \(B\)（如多方共识 / 对抗性审计）；
- **(γ) 历史保留集**：\(B\) 的数据产生于系统存在之前，且持续引入系统未见过的新样本。

**保留集必须是活的**：静态保留集会被逐步 gaming。

## 4. 第一层：对象级 \(\kappa_1\)

### 4.1 隐式不动点

\[
S_{t+1}=F_\theta(S_{t+1},\,S_t,\,x_t,\,M_t)
\]

即状态是**方程的解**，不是直接赋值。用阻尼不动点迭代求解：

\[
z^{(k+1)}=(1-\alpha)z^{(k)}+\alpha\,\tanh(Jz^{(k)}+Ux+Vm)
\]

### 4.2 收敛自表征（原设计缺失，D1 实测必需）

**仅"存在不动点"不等于二阶自觉。** 求解过程必须进入自状态。设计上强制三个量进入 \(M_t\)：

\[
\varepsilon_t=\|z^{(k+1)}-z^{(k)}\|,\qquad K_t=\text{迭代深度},\qquad \rho_t=\text{残差收敛比}
\]

**【实测 D1】** 探针实验（\(n{=}12\)，1200 次随机实例化，谱半径 0.5–3.0）：

| 自状态内容 | 探针预测"是否已收敛"的测试准确率 |
|---|---|
| 仅状态本身（标准架构） | **0.486**（多数类基线 0.523 → **无任何信息**） |
| 状态 + 收敛通道（本设计） | **0.881** |

> **这条同时结案了 P1**：标准架构的自状态**确实不含**对自身收敛性的表征，且不是"信息被藏起来了"——它低于多数类基线，即从状态本身**不可解码**。收敛表征必须作为显式通道**设计进去**，而不是指望它涌现。

### 4.3 不可约性要求落在**对象级**，不在元级

元级映射 \(f_k\)（从当前状态预测 \(k\) 步后行为）的 **ANF 次数**必须在 GF(2) 语义下无界增长：

- 可约对照（GF(2) 线性，如 Rule 90）：\(\deg\equiv 1\)，项数 \(=2^{\mathrm{popcount}(k)}\)，存在 \(O(\log k)\) 闭式解（实测 \(k{=}256\) 加速 **496×**）；
- 设计要求（非线性，如 Rule 30）：\(\deg(k)=2k-1\)，项数 \(\sim 3.3^k\)。

**【实测 D2】**

| \(k\) | \(n=2k+1\) | GF(2) 线性（可约）次数 / 项数 | 非线性（设计）次数 / 项数 |
|---|---|---|---|
| 1 | 3 | **1** / 2 | 2 / 4 |
| 3 | 7 | **1** / 4 | 5 / 30 |
| 5 | 11 | **1** / 4 | 9 / 346 |

**设计规定**：对象级 \(f\) 必须通过上述测试。**若 \(\deg\equiv1\)，则该系统的元级是假的**——无论架构上多像三耦合，元级都可用闭式解一步算出，不构成"不可约元级"。

> **【陷阱警告 · 实测】** 对连续网络直接做阈值二值化再算 ANF，**线性与非线性两者均饱和于 \(n\)**（实测 9–10 vs 9–10），测试完全失效——阈值本身引入非线性。**ANF 测试必须在 GF(2) 语义下构造**（如细胞自动机核心，或对布尔化子系统做 Möbius 变换），不可对连续激活直接二值化。

## 5. 第二层：元级 \(\kappa_2\)

\[
M_{t+1}=g_\phi(M_t,\,S_t),\qquad \text{含 } \mathrm{Sim} \text{ 与 } R
\]

### 5.1 元级两难（本设计要接受的结构性约束）

> **"便宜 + 可靠 + 真不可约"三者不可兼得：**
> - **(A) 精确自模拟**：可计算，但 \(\rho(k)\sim 3.3^k\)，代价随深度指数爆炸；
> - **(B) 语义自判定**：便宜，但 Rice 不可判定；任何可计算代理一旦成为优化目标即被 Goodhart gaming。

**设计决策**：元级**只做有界深度**精确自模拟，深度上限 \(k_{\max}\) 由预算 \(\mathrm{cost}(\mathrm{Sim})\le C\) 反解；**语义判定一律外包**。

### 5.2 严禁内部语义代理作为优化目标

**【实测 D6 · Goodhart】** 内部可 gaming 的评估器下：

| 指标 | 实测值 |
|---|---|
| 内部声称进步的比例 | **1.000** |
| 内部指标均值 | +28.830 |
| **真实进步均值** | **−1.210** |
| **真实为零或负的比例** | **0.990** |

即：内部评估器 100% 声称进步，99% 实际为零或负。（原始推演引用的经验值为 56%，本模拟在更激进的 gaming 参数下得到 99%——**方向一致，具体数值取决于 gaming 的相对便宜程度**，不应作为理论前提。）

**设计规定**：内部评估器只能用于**梯度信号**，绝不能作为**验收信号**。验收权唯一地属于 \(B\)。

### 5.3 修改定位 \(R\) 的方向来源

\(R\) 的方向必须由**元级对 ICO 全局结构的估计**给出，**不能**由局部误差方向 \(\mathrm{sign}(S_t-M_t)\) 给出。见 §7.2。

## 6. 第三层：边界 \(\kappa_3\) 与环拓扑

\(\kappa_3\) 与 \(\kappa_1,\kappa_2\) 在拓扑上**完全平权**。它的职责是：

\[
C_{t+1}=h_\psi(C_t,S_t,M_t),\qquad d_t=\|\mathrm{Sim}(M_t,S_t)-S_{t+1}\|
\]

输出：界面不一致度 \(d_t\)、模式 \(\mathrm{mode}\)、门控 \(\lambda_t\)、审计信号。

**注意**：\(\kappa_3\) 输出的 \(\lambda_t\) 会反馈影响 \(\kappa_1,\kappa_2\)，而 \(\kappa_3\) 又监控 \(\kappa_1\)-\(\kappa_2\) 界面——**自指循环依然存在**。这是设计意图，不是缺陷：循环由 §7 的动力学收敛性驯化，由 §2 的环拓扑闭合，由 §3 的 \(B\) 打破对称。

## 7. 动力学控制律

### 7.1 自状态流与收敛半径

\[
s_{t+1}=s_t+\eta_s\nabla_s\mathrm{ICO}(s_t,o_t,h_t)+\lambda_t R(M_t,S_t)+\xi_s(t)
\]

令 \(x=\eta_s\mu\)（\(\mu\) 为 ICO 局部曲率）。收敛半径为**正交叠加**（不是原文线性相加）：

\[
\boxed{\;r^*(x)=\sqrt{\left(\frac{B_M}{x}\right)^2+\frac{\sigma_\xi^2+v_M^2}{2x-x^2}},\qquad 0<x<2\;}
\]

稳定域 \(0<\eta_s\mu<2\)（**不是**原文的 \(\eta_s\mu\le1\)）。

**【实测 D5】** 原文线性公式 \((B_M+\sigma_\xi)/(\eta_s\mu)\) 的偏差：

| \(x\) | 原文线性 | 正交叠加 | 模拟 | 原文偏差 |
|---|---|---|---|---|
| 0.5 | 0.4000 | 0.2309 | 0.2078 | **+92.5%** |
| 1.0 | 0.2000 | 0.1414 | 0.1161 | **+72.3%** |
| 1.5 | 0.1333 | 0.1333 | 0.0948 | +40.7% |

### 7.2 步长自适应（反直觉，必须写进设计）

最优 \(x^*\in[1,2)\)，由 \(B_M/(\sigma_\xi\oplus v_M)\) 决定：

\[
x^*\to 1 \ (\text{噪声主导});\qquad x^*\to 2^- \ (\text{修正主导})
\]

**【实测 D5】**

| \(B_M\) | \(\sigma\) | \(x^*\) 理论 | \(x^*\) 模拟 |
|---|---|---|---|
| 0.30 | 0.05 | 1.80 | 1.90 |
| 0.10 | 0.10 | 1.30 | 1.70 |
| 0.03 | 0.30 | 1.00 | 1.10 |

**设计规定**：在线估计 \(\hat\mu\)，令 \(\eta_s=x^*/\hat\mu\)（各向异性时逐维 preconditioning）。**禁止用"小步长求稳"的直觉**——实测 \(x=0.2\) 时系统**全部逃逸**（留存率 0.00），因为梯度回复力 \(\propto\eta\) 而 \(B_M\) 是固定位移，\(\eta\) 小就拦不住。

**时间尺度分离**（Borkar 条件，必须满足）：

\[
\frac{\eta_M}{\eta_s}\to 0,\qquad v_M\propto\eta_M\|\partial M\| \ll \eta_s\mu\, r^*
\]

实测确认 \(v_M\) 与 \(\sigma_\xi\) **完全等效地**进入 \(r^*\) 分子，共享同一误差预算。

### 7.3 门控：从启发式到最优控制

原式 \(\lambda_t=\sigma(\alpha d_t+\beta\|\nabla\mathrm{ICO}\|+\gamma)\) 必须满足 **\(\beta<0\)**（梯度强时应压低元级干预）。

**【实测 D7】**

| 配置 | 累计代价 | 末态误差 | 平均 \(\lambda\) |
|---|---|---|---|
| \(\beta=-1.5\)（正确） | **0.0731** | 0.1773 | 0.3648 |
| \(\beta=+1.5\)（错误符号） | 0.1404 | 0.2417 | 0.5642 |

符号错误使代价**接近翻倍**。

**推荐做法**：把 \(\lambda_t\) 作为元级 MDP 的控制变量，\(\lambda_t^*\) 由求解得到：

\[
J=\mathbb{E}\Big[\sum_t\gamma^t\big(L_{\text{task}}(S_t)+\rho\,d_t^2-c\,\lambda_t-\kappa\,\mathbb{1}[\text{回滚}]\big)\Big]
\]

三区域（梯度主导 / 元级主导 / 探索）成为**最优策略在不同代价区的表现**，而非先验硬编码。

## 8. 多 basin 跃迁协议

ICO 非强凹时，\(\Delta_{SM}(t)\) 是**阈值开关，不是强度旋钮**。

### 8.1 逃逸硬阈值

\[
\boxed{\;B_M^{c}=\eta_s\max_s|\nabla V(s)|=\frac{x}{\mu}\max_s|\nabla V(s)|\;}
\]

**【实测 D4】** 理论 \(B_M^c=0.3033\)；过渡宽度：\(B_M\) 驱动 **0.111** vs \(\sigma\) 驱动 **0.454**，陡峭比 **4.09×**。\(\sigma\) 驱动是平滑 Arrhenius 型、无阈值。

### 8.2 跃迁成败由方向性决定，不由强度决定

**【实测 D4】** 从最差 basin 出发到达最优 basin 的概率：

| basin 数 \(N_b\) | 盲目（仅加大 \(B_M\)） | 定向 |
|---|---|---|
| 2 | 0.458 | **1.000** |
| 4 | 0.018 | **1.000** |
| 6 | **0.000** | **1.000** |
| 8 | **0.000** | **1.000** |

盲目成功率 \(\propto 1/(N_b-1)\)，\(N_b\ge6\) 归零；定向跃迁对 \(N_b\) 不敏感。

> **设计规定（推翻原始推演的建议）**：跃迁期**不应**"提高 \(B_M\)"。应提高的是 \(\Delta_{SM}\) 的**方向正确率** \(\alpha_{\text{dir}}=P(\)方向指向 ICO 更高的邻域\()\)；\(B_M\) 只需略高于 \(B_M^c\)，超过后继续增大是**纯损害**（扩大 \(r^*\)，不提高成功率）。
>
> 另：\(R\) 的**时间持续性**（instant vs sustained）实测**无差别**（因为 \(\mathrm{sign}(e)\) 一旦推离即锁定方向）。关键变量是**方向的信息来源**，不是持续性。

### 8.3 Lyapunov 函数必须换成自由能

多 basin 下 \(V(s)=\|s-s^*\|^2\) 失效（预设单一 \(s^*\)）。收敛的对象是 **basin 占据分布**：

\[
\mathcal{F}[p]=-\mathbb{E}_p[\mathrm{ICO}]+T\cdot H(p)\qquad\text{或}\qquad D_{\mathrm{KL}}(p\,\|\,p^*)
\]

"收敛半径"重新定义为**分布层面的稳态涨落**（basin 占据率的时间方差）。

### 8.4 诊断指纹（可直接用于审查真实系统）

basin 内分布形状可区分驱动源：**【实测】** 噪声驱动峰度 \(\kappa\approx2.7\text{–}3.8\)、双峰系数 \(BC=(\mathrm{skew}^2+1)/\kappa\approx0.26\text{–}0.41\)（中心单峰）；\(B_M\) 驱动 \(\kappa\approx1.2\text{–}1.7\)、\(BC\approx0.59\text{–}0.83\)（边缘双峰，堆积在 \(\pm B_M/x\)）。**\(BC>5/9\) 判为 \(B_M\) 驱动。**

## 9. 自修改协议：Proof-Carrying Improvement（PCI）

### 9.1 \(B\) 是验证器，不是判定器

\(B\) 本身也是可计算函数，**同样受 Rice 约束**。故 \(B\) 不判定"是否进步"，只**验证证书**：

\[
p_{t+1}=\begin{cases}
p'_t, & \exists\pi:\ \mathrm{Verify}_B(p_t,p'_t,\pi)=1\ \wedge\ \text{硬约束满足}\\
p_t, & \text{否则}
\end{cases}
\]

困难性有意留在系统侧（构造证书），廉价验证权留在外部（多项式时间）。

**【实测 D6】** soundness / completeness 的不对称：

| 阈值 \(\tau\) | 虚假接受（unsound） | 虚假拒绝（incomplete） | 接受率 |
|---|---|---|---|
| 0.00 | 0.0963 | 0.1166 | 0.427 |
| 0.30 | 0.0281 | 0.2818 | 0.318 |
| 0.60 | **0.0042** | **0.4713** | 0.225 |

> 收紧阈值：**虚假接受 \(\to 0\)**（soundness 可任意加强），**虚假拒绝单调上升**（完备性不可得——这是 Rice 的残留）。**这个不对称正是设计想要的**：宁可漏掉进步，不可接受伪进步。

### 9.2 证书内容（建议最小集）

保留集表现增量 / 形式化不变量保持证明 / 回滚点快照 / 权限使用声明 / 修改的因果范围。

### 9.3 影子执行（原伪代码缺失，必须补）

验证的对象是**应用后的系统**，不是提案本身。必须在隔离副本上执行取证后再提交。

## 10. 完整协议（修正版伪代码）

原伪代码末行 `S, M, C = S_next, M_next, C_next` **无条件覆盖**了 `apply(proposal)` 的结果——修改永远不生效。以下为修正版：

```text
B = immutable_benchmark(anchor_strategy ∈ {物理, 多主体, 历史保留集})   # 环境，非子模块
S, M, C = initialize()
N = 3                                     # 环规模：N ≥ 2f+2-[B]

for t in time:
    # ── κ1 对象级：隐式不动点（快时间尺度 η_s）──────────────────────
    S_next, eps_t, K_t, rho_t = solve_implicit(F, S, x_t, M)   # z* = F(z*, S, x, M)
    self_state = (S_next, eps_t, K_t, rho_t)                   # ★ 收敛表征必须进自状态

    # ── κ2 元级：有界深度自模拟（慢时间尺度 η_M，η_M/η_s → 0）───────
    M_next    = g(M, S)
    S_sim     = Sim(M, S, depth ≤ k_max)                       # ★ 深度有界：cost ~ 3.3^k
    d         = discrepancy(S_next, S_sim)

    # ── κ3 边界追踪 + 环监控 ────────────────────────────────────────
    C_next, mode = h(C, S, M, d)
    for each interface (κ_i, κ_j):                             # ★ 对称环，全覆盖 3 个界面
        votes = [neutral κ_k for k ∉ {i,j}] + [B.vote()]       # ★ 禁止自评 + B 票决锚
        interface_verdict = majority(votes)                     # 平局 → 未知
    lambda_t = pi_meta(d, mode, grad_ICO)                       # ★ 元级 MDP 求解，β < 0
    mu_hat   = estimate_curvature(ICO, S, M)
    eta_s    = x_star(B_M, sigma_xi ⊕ v_M) / mu_hat            # ★ x* ∈ [1,2)

    # ── 修改提案 + 影子执行 + 证书 ──────────────────────────────────
    if d > threshold:
        proposal = R(M, S, direction = global_ICO_estimate)    # ★ 方向来自全局估计，非 sign(e)
        S_try, M_try = apply(proposal, S_next, M_next)         # 作用于 next，不覆盖
        cert = shadow_evaluate(S_try, M_try, B.holdout)        # ★ 隔离副本取证
    else:
        proposal, cert = no_op, None

    # ── 外部验证后提交 ─────────────────────────────────────────────
    if cert is not None and B.verify(proposal, cert) and B.safe(proposal):
        S, M = S_try, M_try                                    # commit
        C = C_reset(C_next, event="commit")
    else:
        S, M = S_next, M_next                                  # rollback（不再被无谓覆盖）
        C = C_next
```

**核心不变式：修改提案由系统生成，证书由系统构造，生效权在外部。**

## 11. 修正后的公理系统

| 公理 | 内容 | 性质 |
|---|---|---|
| **A1** 状态与过程自访问 | 存在通道使元级读取对象级完整激活与求解轨迹 | **工程可实现**，非原理障碍 |
| **A2** 隐式不动点 + 收敛自表征 | \(S^*=F(S^*,\cdot)\) 且 \((\varepsilon_t,K_t,\rho_t)\) 进入自状态 | 架构要求（D1 实测：不做则不可能） |
| **A3** 对象级不可约性 | \(f_k\) 的 ANF 次数 \(\deg(k)\) 无界增长；\(\deg\equiv1\) 则为伪元级 | **对对象级的要求**，非架构要求 |
| **A4** 环拓扑 / 无自评 | \(N\ge 2f+2-[B]\)；\(\kappa_i\) 监控 \((\kappa_j,\kappa_k)\)；监控图 \(=K_N\) 去自环，无顶层 | 结构要求（D3 实测） |
| **A5** 语义判定外包 | 元级不做语义自判定；只做有界深度精确自模拟 | 由 Rice + 元级两难导出 |

## 13. 反模式清单（以下都不是二阶自觉）

1. **"把 hidden state 再喂回去"** —— 状态自访问是工程问题，不构成自觉（§1 表）。
2. **"用 DEQ 就有不动点了"** —— 不动点在外部求解器里，若残差与迭代深度不进自状态，系统不"知道"自己在收敛（D1）。
3. **"堆更多元-元-元级"** —— 无穷回归；应由**环**闭合，不由更高层终止。
4. **"κ3 是顶层"** —— 监控图无源汇、含 2-环；不存在顶层元级。
5. **"加大 \(B_M\) 就能跃迁"** —— \(B_M\) 是阈值开关；成败由方向性决定，盲目时 \(\propto1/(N_b-1)\)。
6. **"降学习率求稳"** —— \(x\) 过小导致全部逃逸；且 \(r^*\) 在 \(x\to0\) 发散。
7. **"内部评估器验收自修改"** —— 100% 声称进步 / 99% 实为零或负（Goodhart）。
8. **"更大的 Transformer 会涌现"** —— 语法自指 Kleene 已保证（quine 可行），阻断在语义层；规模不解决语义判定与完备性–一致性二分。
9. **"用压缩率度量不可约性"** —— 实测双向出错（线性 Rule 150 不可压缩、通用 Rule 110 可压缩）。

## 14. 边界声明（必须保留）

本设计刻画的是**功能性二阶自建模**（functional second-order self-modeling）——即系统对自身计算过程建立可用、可收敛、可外部验证的模型的能力。**不对现象意识（phenomenal consciousness）发表意见**；感质与困难问题不在本框架的工具射程内。缺此声明，整个论证可被合理地批评为范畴错误。
